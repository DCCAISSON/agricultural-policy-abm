# 可分享汇总：2011年调查兼种、模型纯经作的家庭

仅本目录为汇总交付。上一级的 `PRIVATE_DO_NOT_SHARE` 含可链接模型ID、调查源行与逐户经济账，不得外传或纳入外审包；本目录没有这些标识。两个种子模拟同一批家庭，不把两组户数相加当作独立样本。

## 为什么模型选择纯经作

2011年固定观察点可靠匹配562户，其中340户的粮、经年度播种面积均为正。按新规则基线的实际经营者粮经面积筛选，这340户中种子103有192户、109有198户只种经作；核对选择记录，这些户也全部在季前选择了纯经作。以下为每户先按季前经营面积折亩、再等户取均值；不是实际销售、实际成本或全国均值。

两个种子中，上列每个方案至少有一种可行作业方式。相对保持原组合，纯经作每亩预期销售分别多2368、2347元，现金成本多714、751元；销售溢价超过增支。在这些方案的逐户账中，风险扣分与调整支出均为零；家庭劳动日不是另扣一次的现金成本。原组合本来就是纯经作的分别有4、3户，另188、195户的纯经作得分优势超过了各自沿用原方案的惯性门槛。不能把模型内部的收益排序当成调查家庭面对的实际价格或改种原因。

“最小增加”分两种：表中是从零出发、在该户现有候选中取最小的可行正粮份额，不是假定存在任意小的调整。另按“从上年组合再增加一档”比较，分别有185、189户有此可行方案，平均比同户纯经作低1832、1783元/亩；其余7、9户上年已全粮。保持原组合可与纯经作或纯粮端点重合。每个份额比较自作与外包，取可行方式中得分最高者；并未只保留实际选择。

## 调查与模型的双零

- **调查没有缺失的粮经总项。** 562户的粮经两项均非空；45户两项均为零，其中14户其他作物播种面积为正，31户总播种面积也为零。后31户中8户年末经营耕地为正、23户该字段为空；总播种为零不证明家庭因资金不足停种或已经退出。
- **季次未观测与作物细项缺失是两回事。** 在两组目标户中，六项粮食作物细分面积至少一项空白的分别有188、194户；经济作物有总播种面积，但这张户表没有逐种经济作物的面积列。其他作物为正的分别有33、30户，不在粮经份额的分母内。分别有163/192、170/198户的总播种面积超过年末经营面积；年内土地增减和跨季复种均可能产生这一差额。户表没有地块与季次的对应，因而无法将任何一户的模型偏差确认为漏掉某一季或某一作物。
- **模型有当年行动与土地账。** 在562户中，两个种子各有121、117户实际粮经面积均为零：各64户季前选择退出；另外57、53户选择继续生产，但季前结算时已无经营地，且均有当年供出土地的成交记录。仅限调查兼种340户，模型双零分别为66、63户：40、40户选择退出，26、23户继续生产但已无经营地。这里的退出是模型当期行动，不是调查户失访；这些双零户也不计入上述192、198户纯经作。

## 文件与核对口径

- `mean_paired_accounts.csv`：只对可行方案取等户均值。`delta_*` 是同户方案减纯经作；金额为元/季前经营亩，劳动为日/季前经营亩，份额为0至1。现金成本亦为所需季前资金，含生产、服务、租入、管理、调整；雇工支出已计入生产成本，不重复相加。资金余额为可用减所需。得分还包括支持、转出地租、非农和共同收入，再扣现金成本与风险。惯性是年度选择门槛，不在得分中重复扣除。
- `availability_counts.csv` 按比较对象分别报告可行、不可行、无此备选；`choice_constraints.csv` 列各行动、自作/外包/转出方式、账面约束、服务是否可用及计数。103与109各有1960、2018条备选方式账，其中1906、1957条可行；备选数不是户数。
- `survey_model_class_counts.csv` 为两个种子的四类交叉表及模型双零证据；`survey_double_zero.csv` 为调查双零的非重复计数；`annual_crop_coverage.csv` 为目标户的年度作物资料覆盖。
- 复算：从项目根目录执行 `.venv/Scripts/python.exe -B -X utf8 -m scripts.audit_portfolio_2011_decisions`。直接回读固定观察点2009–2015户表、冻结job8源行，复核2011年同户键及全部粮经面积；模型输入为 `runs/s{103,109}_new_base_20261121_220058_199520/episode/year_01` 的选择、备选、收获、土地成交与季前资金账。逐项重算得分并核对实际粮经面积之和与资金账耕作面积。没有调用模型、调参或运行政策。
