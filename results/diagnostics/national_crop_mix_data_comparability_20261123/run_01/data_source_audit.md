# 家庭粮经选择的年度可比性与五年外推

**判断。** 后期失配包含调查构成变化，但不能归结为“数据有问题”。在固定的家庭中，年度兼种也减少了。现有问卷和字典没有提供2014年突然改口径的证据。同一家庭、同一年度、同一个抽取数，只换掉模型使用的上年种植记录，下一年粮食份额分布就会明显改变。这个对照直接说明模拟历史的累积误差是后期失配的一项来源。

**调查与样本。** 固定观察点2009至2015年户表区分粮作、经作、其他作物的年度播种面积，以及年初、年末经营耕地。前者计全年作物播种，同一块地跨季先种粮后种经作也会使两类均正，不等于同季地块混种；户表没有季次和地块对应关系。面积单位为亩，投工为日，农资费用为元，家庭劳动力为人数。土地增加和减少是流量，“其中转包入、转包出”不是全部增减。逐年原字段、原标签、负值、缺失与零见 variable_by_year.csv。面积来自当年户表，不把年末经营面积作为全年播种的上限。

所见问卷是覆盖该段时期的合订资料，不能据此认证每年单独的问卷版本、访问日、跳题执行和空白编码均相同。七年三项播种汇总没有空值；2015年21,264行的“总播种减粮经”全部与其他作物列相符，2014年20,640行中20,638行相符。实测差额保留，不分摊。土地年初加全年增加减全年减少与年末数的完整记录，2015年仅1,651条，其中1,639条平衡；未填转出不能当成零。证据：account_coverage.csv。

各年度全样本兼种比从2009年45.2%降至2015年31.2%；2011至2015年连续450户从59.8%降至40.2%，其正播种户粮食份额中位数却由88.2%升至90.9%。因此，兼种减少并不等于粮食占比下降，更不是全由换样造成。450是五个评价年均按原键匹配，不表示2009至2015年七期完整。年表另列固定队列能匹配的家庭，以及基期估计户；身份连续性较严格的两期样本另作转移与回测。样本频率不是全国加权频率。详见 annual_distribution.csv、balanced_panel_distribution.csv、annual_composition.csv、household_attrition.csv。

2010年兼种比例依次为：来源样本43.1%、符合现有入选条件55.8%、加校准权重后60.8%、实际600户63.8%。全样本未播种22.6%，队列仅2.2%。按种植状态及上年份额分组、地区、经营规模、家庭劳动力和流转身份比较，队列与原样本的联合分布总变差距离为0.374。入选条件、加权和有限户数选择的差异分开列在 initial_cohort_comparison.csv。队列适合比较同一批家庭的机制，不是来源样本的等比例缩影，也不能把上述差额全归于CFPS。没有逐户放大土地和劳动力。

**时间外推。** 基期17,027对非队列、同地区且经成员连续性确认的相邻记录中，12,884户次年粮经至少一类为正，另4,143户不进入正播种条件份额的估计。六个相邻年度中，兼种户在次年继续播种时继续兼种的频率约87%至90%，但完整转移矩阵并不恒定。例如，2014至2015年纯粮转兼种的频率较2009至2010年低7.97个百分点，家庭聚类标准误0.57个百分点。此处只比较可确认的去向；transition_matrix_by_year.csv另把无法判断的去向计入分母，列有地区和经营规模分组，不能混用两处分母。地区和样本选择未随机化。转为其他作物不同于停止全部农业生产。

固定使用基期历史的五次一步预测中，连续法把条件平均份额的户级绝对误差从0.140降至0.105；五个分位数平均误差从0.047降至0.021，条件分布得分CRPS从0.096降至0.070（均越低越好）。扩大历史窗口后，连续法分位数误差为0.018；状态分布总变差距离却与离散法相近。预测每次只读取目标年份以前的非队列家庭，评价户使用实际上年历史，不等同于五年递推的ABM。固定早期合并窗口最晚止于2012年；各窗口按年等权汇总。

2016、2017年原户表实有6,296、5,956行，粮经总项 d30/d31/d35/d36 各年有效数均为零。小麦、稻谷、蔬菜等明细并非全空。逐种粮食和经作明细全部非缺、合计为正且与600户同码的，仅2行和1行；同码尚不等于确认追访。不能将其余明细空白补零来拼一个独立验证期。本轮五年是历史回测和模型开发诊断，不是新的时间外验证。见 later_availability.csv、later_item_coverage.csv。

**收益代理。** 经作亩均5,131元是较晚年份蔬菜和水果的销售额代理，不是所有经作的单价或净利润。按实售记录和播种面积加权，2016、2017年蔬菜分别为5,002、5,555元/亩，水果为8,008、4,435元/亩（2024年价格）；相应工日分别约80、82及35、17。换用这四个已有组均值，单亩销售收入相对原代理可从少约695元到多约2,877元；这是预算敏感范围，不是农户选择变化的估计。记录地区和品种构成都不相同，一般CPI平减不能消除相对价格差异。成本原记录已折为2024年价格，只对销售额补做一次换算。机械作业费不换算成工日，不重复扣作业费。无法从这些预算识别2009至2015年每户同季的销路、非农工时损失或各种经作的真实利润。

**全出租。** 在2015年上年调查实际粮食份额高于80%的246户中，221户继续种粮；205户没有转包出数。限定期初地为正、无新增、土地增减资料完整且平衡，只有13户可判，观测到0户全部出租，模型在这13户中分别判作4户和3户。不能用0/13估计全部246户的退出率。另取模型内高目标、实为全出租的99/88户，固定目标份额、亩均收益与可用自有地，对资金约束、家庭劳动约束、可出租机会做八组季前反事实。三者均放松时分别可种475.0/494.4亩；按六种加入顺序平均，出租机会减少421.8/452.9亩，资金减少43.3/34.5亩，劳动减少9.9/7.0亩，加回实际零亩。这里比较自营和按预期租金出租，不是现实租金弹性，也不是关闭整个土地市场后的均衡。家庭非农收入按现有设定给定；预算内家庭劳动的边际现金扣费为零，真实农忙机会成本尚未识别。

**模型修订与结论。** 只修正份额形成：区分纯粮、纯经、未种与兼种家庭；兼种者按上年实际份额找到最近的历史家庭，保留并列距离，按固定抽取数从其次年正播种份额分布取值。邻居数取该组样本数平方根向上取整，是不按结果调整的平滑假设。是否经营、经营多少、是否出租仍由原有预算、家庭劳动和土地交易决定，收获后更新下一年历史。目标比例并非对当前价格重新优化出的替代弹性。未新增退出概率，也未改作物价格、工资、补贴或组织效率。

两种子的原定行为验收共十项，v1通过六项，v2通过七项。2014年份额误差从0.193/0.254降至0.133/0.200；2015年从0.294/0.254变为0.242/0.274，第二条路径变差。2012年调查476户播种，新模型425/435户；2015年经作面积调查829.6亩，模型1,846.5/1,947.1亩。不能用早期份额拟合改善来代替参与与总量验证。

2015年共同播种且有相邻年记录和目标的309/305户，保留当期同一抽取数时，以上年调查事实生成的目标份额分位数误差为0.028/0.034，以上年模拟实种生成的误差为0.211/0.237。回放只替换历史输入，不改变成交及当期参与，也不把调查结果喂给正式模型。这区分了“一步份额能预测”与“模型能生成可持续五年的家庭经营历史”。同户份额变化、播种规模变化、参与进出对两个模型粮食面积差的对称分解逐年加回总差；租入土地上种了多少粮只有上下界，没有补造地块用途。

**处置。** 发布第二候选供复核，不替换基准，不解锁政策实验。只保留一项有辨识力的后续检验：用不参与本轮选择且经营权转出记录完整的样本，验证高粮家庭“全年不种”和“全地出租”是否真实同时发生，再判断是否改参与和租地规则。现有模型反事实能定位租金选择，却不足以估计该项现实行为，故不进行第二轮调参。
