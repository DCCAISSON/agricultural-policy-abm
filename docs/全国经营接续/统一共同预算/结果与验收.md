# 四区共同预算：八年决策与停付试验

## 研究结果

固定、短视和Q使用同一600户、同一块土地、同一地区气候种子和同一期初共同额度。三项主对照产物由48个互相独立的评价种子配对，每条路径同时包含四区，而不是把地区年度当独立样本。开发期16个种子从21种固定动作中选出 `fixed_11`：八年均将额度集中于西部，按合格实种粮地在收获后支付。短视和Q使用同一批768个开局，每个均有21种分叉动作；两者只在是否计入跨年产量上不同。

六项为族置信度95%的同时区间。相对地区固定，Q 更少投入西部、更多投入中部，西部约少331.51吨约抵消中部多169.23吨。相对短视，Q 也更经常在中部投放普遍播前支持，384次主路径决策中84次投中部（短视47次）、216次投西部播前（短视248次）。Q有72次因样本不足和5次因未见状态回退P0，不能把较低实际支出解释为在同等生产下节约，也不能把差异都归因于前瞻价值。

同一共同上限下，始终无新增专项的八年产量为11,611.94吨，均分普遍播前为12,280.08吨、实付56.85万元。集中于西部的固定方案比上述均分点估计产量高、实付也高，未据此给出优先顺序。Q相对P0多出的同一经营者原地连种为1,253.43亩年，换人同地连种多25.59亩年；Q自身八年新成交1,782.31亩年，签约而未播为291.39亩年（均为模拟量）。这些差异说明本模型中接续发生，但财政改变原经营者的作物选择，并不等同于形成更多实际承接。

### 停付

各策略从完全相同的本策略第六年末分叉。Q在第7–8年停付比继续执行同一冻结政策少142.54吨，未校正的配对95%区间[−162.57，−122.50]；与始终P0比少10.18吨[−15.84，−4.52]。固定和短视的停付结果也低于各自继续执行。账中仍有已签合同和尚在经营的家庭，但这不能当成停付后增产已经保留。差异能追到账目，不在本轮把现金结转或在履合同定为唯一原因。[停付对照](结果/withdrawal.csv)逐项列产量、租金、在履合同、同地续粮和签后未播，未给这些结果另定权重。

## 三项验收分开

| 对象 | 裁决与证据 |
| --- | --- |
| 模型运行与结算 | 完成且核验。原600户、5,277.5亩物理面积、4,009.2亩可核承包部分、2,210个合成经营单元；逐年租赁、播种、契约与现金实际更新。39,936条地区年度逐行复核；另运行逐户逐地块核账112个地区年度，涉及16,800个家庭年度、61,880个地块年度。 |
| 家庭行为 | 完成历史对应检查，不能验收为贴近调查。P0用同户核对2011–2015年的参与、兼种与产量，四个开发种子，不用比较结果重估。2011年可比569户中，参与为调查539与模拟508.25，兼种293与23.75；2015年可比534户中，参与445与448、兼种207与14.50。2015年同户粮产为调查2,381.24吨、模拟1,344.07吨。模型一季的物理种植亩与调查的年播种亩次不同，表中不把两者作同一指标验收。 |
| 外部有效性 | 因缺独立家庭递推面板未能判定。省级样本不是现实租地市场全体；没有将合同和真实地块同户相连。工日、工资机会和小地块均有明确代理或结构设定。不把结构实验概括为现实行政区推荐、因果效应或全国预测。 |
| 政府学习 | 实际训练及独立模拟评价完成。常见状态动作支持924/1,722（53.66%），低于95%；不宣布Q有增量价值。按既定种子和指标报告负结果与不可辨别比较，不重调权重、延长训练或丰富菜单追分。 |

[家庭对照](结果/historical_household_comparison.csv)分开匹配记录与调查有效分母；[地区年度核验](结果/receipt.json)、[微观核账](结果/household_accounts_receipt.json)与[动作频数](结果/action_counts.csv)为可公开的汇总证据。
