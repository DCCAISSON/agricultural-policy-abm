# 四区连续分配：新评价与裁决

从四区 `358bdf9` 继承市场与财政入口。唯一主农业环境为M1，混作搜索修订关闭。共同上限98,953元与21个合法动作不变；主试验第1–8年均可分配，停付另从本策略第六年末分叉。地权和行政区用真实队列数据；宗地及租赁关系是模型构造，不是地理相邻或现实省级市场。

## 开发支持与评价

16个新固定开发种子选出西部集中普遍播前支持（`fixed_09`）；其余合法固定也都评价。144个首批父路径的常见状态支持为74.36%，触发唯一一次144父路径补充。开发共筛2,304个年初，110个不同公开状态；对来自251个父路径的784个开局分叉21动作。各年常见状态为至少该年288个筛选开局的2%（向上取整为6），每个状态—动作须有至少五个独立父路径的有效开局。最终常见状态支持 **1,428/1,428（100%）**，全部访问状态支持80/110（72.73%），按筛选开局频率加权96.57%。主Q评价384次决定中19次回退P0、无未见状态；短视21次回退。短视和Q同信息、同数据，同一状态从至多十个不同父路径中得到的21个动作仍只算十个开局。

重复拟合按登记删去可被4整除的父路径后用591个开局，常见状态覆盖92.65%；其Q对同次短视的产量点差为+8.37吨、实付+0.90万元，产量的描述区间跨零。重复Q比主Q八年少26.13吨（未校正95%区间[−43.14，−9.12]），说明学习结果仍受开发样本影响，不选胜者替换主表。[源表重算回执](结果_sprint/government_receipt.json)、[动作与回退](结果_sprint/action_counts.csv)及[复拟结果](结果_sprint/stability.csv)。

## 政策停止与经营反馈

Q停付两年比继续原策略少176.82吨，未校正配对95%区间[−193.47，−160.18]吨；比始终P0少9.91吨[−15.84，−3.98]吨。不能把前六年的增产直接称为停补后留下的产能。逐项支出、在履合同、换人续粮和签后未播见[停付对照](结果_sprint/withdrawal.csv)。

首年将同一普遍播前工具集中给中部而非西部，随后都采用相同均分政策和同一气候路径。中部的增加严格压缩了西部的当年可承诺额度，首年四区合计实际支付少1.18万元、粮产少11.76吨，模拟机制账涉及少12.04亩新成交和期末少1.27万元可用余额；下一阶段仍有在履面积差，但第2–8年累计粮食差为−10.74吨，区间[−23.61，2.13]跨零。这说明本模型的初期配置确实传导至现金和合同，尚不能把后续产量或Q的表现唯一归因于任何一条通道。[首年试验源表](结果_sprint/allocation_pulse.csv)为未校正的描述区间，不用于训练准入。
