**留出不能成立的两个独立理由。**

1. **已接触。** 2011–2015 年已用于多轮选择与修订；F1 `prepare_nfps_v3.py` 用不含队列的截至 2012 年相邻户年估计方向，外部池还逐年使用当年之前的非队列观察（可做历史条件回放，却不是完全封存的多步预测）。旧 `scripts/audit_crop_time_comparability.py:104–109`、`scripts/audit_national_crop_budget_basis_20261118.py:105`、`scripts/audit_one_mu_hired_days.py:92`、`scripts/audit_productivity_sources.py:94` 和 `scripts/build_nfps_d1_facts.py:216` 已读取 2016–2017 原表；F1 `cash_budget_ranges.csv` 与参数表也使用该段作物预算作敏感性参照。不能把这段称为从未使用的时间留出。亦无先前隔离省、村或样本且未被汇总参数和诊断利用的回执；排除队列参加拟合、换模拟种子均不能补足。
2. **量不可比。** 2016/2017 户表 `d30/d31/d35/d36`（总、粮、经、其他播种面积）以及 `d32–d34/d43/d54` 全无非缺值；`d37–d42/d44–d53` 有零和正值，但分品种缺项模式不能自动判成未种或期望的总量，不能据此做冻结四项。晚期期末总经营面积是 `c18`，不是承包分项 `c19`；唯一户年中 `c2` 非缺 5,064/4,784，`c18` 非缺 4,567/4,272，起末可比且末正 4,215/3,979，连续两年均可比 3,672。仅按 ID 和省码重接冻结 600 户，得到候选连接 169/148，起末可比且末正 141/119，两年均可比 117；原始连接元数据不足，不能把这些候选键当逐地块核验。即使放宽为土地单项外部描述，也不能替代粮经多步经验检验。

一步诊断在某年重新给入当时可得的期初资源，只检验当期选择；用当年期末实测土地替换只能作反事实误差定位。递推留出须从同一共同初态运行，留出期现金、合同、经营和作物史均由模型递推，不靠留出户年结果回填外部池、价格或作物资源。下一步需要有授权、可比总粮经面积和两个以上后续年度的未用面板，或有明确隔离记录的地区/村样本；真实地块升级还要独立获得地籍/合同/季节实种的可核连结。不从现有材料反向再“留出”。
