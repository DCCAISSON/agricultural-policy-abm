# 四区农业经济内核：实算与裁决

**决定：保留共同决策实现和失败结果，不用具名参数替换农业基准。** 本轮纠正了程序中的固定费单位、无成交回撤、混合作物、现金结转和时间账。但实际运行结果未通过家庭行为验收；原四区环境也不是已经验证的经验基准。政府 Q 与政策排序仍关闭。

## 实施与反例

- 原来两块各2.5亩的地单块报价均失败。统一在承租组合上扣一次年度固定费后，原本可负担的5亩组合成交，首年经营现金利润315元；可履约的次年不再付560元新交易费，仍付年度管理费。
- 无竞租者的4亩原来因为假定能赚租金而空置。原经营者能在播种窗口回撤，新账录入实际种粮4亩、地租0；没有把未成交租金计作收入或自营成本。
- 同一现金与农时约束下，粮、菜和空置可以共同出现。单位测试分别核对自留不入现金、雇工支付、用工不重计、组合成交、到期和播前抵减。播前抵减不是通用现金拨款。

## 尚不能识别的经济量

- 早期完整投入账的小麦、稻谷、玉米只有34、211、144条；玉米完整账21.26日/亩，而较宽的有效面积与用工组是9.32。不存在已核实的证据说明全年投工集中在既有农忙窗口，或者后期蔬菜销售预算能替代早期经作价格。后期蔬菜93.23%的市场化比例是1,136条同记录产销报告计算值，不外推为三种谷物的销售比例。
- 东北20户基期超过30亩的固定土地资源对照中，单季实种90.31亩不随现金翻倍而改变，家庭工日翻倍时为205.83亩；按稻谷工资样本中位数的有界雇工未被使用。此处检验的是既定约束的边际影响，不能判定现实大户缺工或能否采用机械作业。
- 2015年534户调查记录只有34户同时报告转包入、转包出，报告两项合计为359.4、37.6亩。仅对两项都报告者的差不能解释为600户整体净交换，也不识别样本外交易容量。家庭年初年末经营亩、在租权、真实地块和期末计划面积分别处理。

下一项最有辨识力的证据是同一时期具名作物的投入、实际售出与有时间窗的工日匹配账。取得之前可复算和使用工程反例；不使用现有历史窗口把候选强行调到通过，也不把旧政府学习结果接到新农业环境。

## 核验

12条配对路径、240地区年度、36,000户年及132,600合成单元年。预算与实付全为零；支付时点由独立边界测试覆盖。保留63项当前相关测试及旧两区专属冻结树的6项测试。投入、价格、劳动、土地与现金的可复算入口见 README。干净树13份汇总逐字节一致，指纹见汇总/verification.json。可交接汇总删去了由少于5条记录构成的工资中位数和少于5户的资源分组；没有原始调查、户号和逐户原账。
