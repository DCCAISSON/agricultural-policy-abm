# 两个合成地区：共同财政预算与跨期分配

**裁决。** 新版单区同信息政府比较通过只读复核。两地区共同预算的首年分配试验未发现有证据支持的首年与八年粮食排序反转。因此本轮不启动两地区地区固定、同信息短视和 Q 策略比较，也不改变经验候选的放行状态。

## 已有同信息结果

附件的八份结果文件、两份生成脚本指纹通过核查。共 2,240 条八年路径、17,920 条年度记录、320 项 Q 配对统计、48 项停补统计；两种策略按原冻结表复算动作。三种主评价情景各有 64 个未参训的种子，另有现金重置敏感性情景。期初仅见剩余期限、上年粮食档和上年支出档。数据结果与旧 7a 在线 Q 不合并，见[政府学习证据](../开发比较/政府学习证据.md)。

Q 相对短视在八年中平均多产 1,641.04 公斤、多实付 2,493.75 元，预定折现评分低 0.02597。停补五年，前三年分别实行普遍播前和承接播前的年均增粮是 696.74 与 69.54 公斤，后者区间跨零。前三年平均实付不同，分别为 15,933.59 与 655.47 元。以已测试策略作产量—支出的均值比较，中间情景固定承接播前支出更低、产量未见可辨别下降；这不等同于各个情景中某种策略都支配另一种。

## 新试验

既有 7a 农业源码指纹未变。两个地区各有 192 物理亩、24 个权利家庭和 8 个潜在承接者；A 使用中间条件，B 使用资金与农忙劳动更紧的条件，参数沿用附件已有合成情景，并非两个现实地区。土地、现金和经营者在各区内部结转，地区之间只有财政竞争，不跨区租地。每年一个共同上限 7,200 元。年初先为两区同时预留，再进入各自竞租与生产；未兑现的预留不调剂、不结转。7a 的新补助在本年结算，没有多年财政应付承诺；一年期租约不改。

唯一允许的工具为 P0 无新增专项、P1 普遍播前、P3 承接播前。共用的菜单包括不支持、任一区低/高档、两区低档，工具可以不同；双高与高加低均拒绝。两个地区正档局部上限 3,600/7,200 元，与 85 元/亩的名义标准在 48 块、每块 4 亩的预留公式下分别产生 **18.75/37.50 元/亩**的事前保证（每个符合条件且实际种粮的地块 75/150 元）。核实际付款也不同，例如 A 地 P1 的低、高档平均实付为 2,499.61/5,133.98 元。保证额不等于事后所有地块都获付。没有规模门槛。

预锁的七组包括始终 P0，以及每种工具首年全给 A、全给 B、各半。后三种使用相同预算上限；实付不必相同。第 2–8 年统一采用 P0，两区分别沿用自身状态，种子范围 330001–330128，同一区在每个比较臂使用同一初态及同一索引冲击。

首年全给 A 减全给 B，P1 的首年/八年粮食分别差 −693.85/−431.29 公斤，P3 分别差 +37.58/+166.51 公斤。四个 Bonferroni 调整后区间均跨零，且两项工具自己的点估计首年和八年方向也一致。各半臂显示有价值的当期配置比较，但不是阶段二的固定策略训练或同等实付下的策略排名。

**沿账追踪。** P3 全给 A 与全给 B 比，首年承接者期末合计现金多 612.18 元，次年同差额进入期初；首年实付也多 155.86 元，故不能归因为等成本地区配置。次年第一个年度没有在履首年合同，重新竞租的成交、改种及实际生产另列。P1 全给 A 相对始终 P0 首年原经营者续种多 8.09 亩，P3 对应的换人续粮多 0.91 亩。七个停补年里，无论分配方案，专项预留、承诺与实付均为零。现金和作物状态有结转，不等于已经识别出足以改变跨年粮食排序的渠道。
