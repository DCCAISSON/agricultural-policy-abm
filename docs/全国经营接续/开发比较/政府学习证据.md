## 三、后续设计：共同预算下到底学什么

**先把地区与金额的可选范围定实。** 一个政府每年为各区联合选择 `不付／合格种粮地支持／合格新增承接种粮地支持`，后两者再区分有依据的播前与产后时点。只列可核资格、政策窗口和拨付方式；其他制度不随行动改变。所有策略使用同一年度总预算、法定专项约束和共同的分配、限额及回退公式。在决策时按已知未结义务、各区资格的可核上界和可兑现单价预留预算，使义务加新可承诺额不超过共同额度；实付按实际播种与核验条件入账，退款、结转或失效按同一规则单列。允许暂不使用额度；不能先让各区各自用尽同一总额度，再用年末实际结果调整。

**金额档按实际进入行为的金额区分。** 7a 名义标准为 85 元/亩，但对 192 亩和 7,200 元预算，[实现](../../../../../land_succession_transmission_final_20261126/worktree/core/land_succession.py#L218)按总地块面积均摊上限，实际用于计算承诺的单价最高只有 37.50 元/亩；实付还取决于资格和实际种粮。多地区菜单先登记零档和少量正档（例如低、高），再用预先可知的面积上界、分区预留及生产成本限制，逐状态核对名义档、上限后的有效档、承诺和实付。若两个名义档在裁切后给出相同资格、时点及有效金额，只保留一个可行动作；若金额不同却不改变任何可行经营决策或后续状态，报告该档在所考察条件下不改变行为。暂不指定经验金额；共同额度、相同承诺和相同实付分别报告。

**比较对象须同信息且足够强。** 冻结决策时点可得的滞后地区粮食、财政额度及实付；下一年度到期合同、签约未播、释放未成交只有核实覆盖、发布日期和核验规则后才可用。Q 与短视读取同一字段、离散阈值、期剩年数与可行菜单，使用共同的财政预留和回退办法，不得看到私人现金、当年收获、未来冲击或评估时的分叉结果。用开发期混合策略访问的同一批期初状态，按共同外生抽样分叉可行动作，估计同信息条件下的当年预期评分，冻结短视规则。报告所有合法固定组合，事前从开发期选统一强固定及在共同预算下可行的分区强固定；同时报告透明规则、基础 Q、预定的改进探索 Q。事后固定最优只作参照。最终评价前锁定选择、权重、回退、种子和动作掩码；不凭评价反馈改规则。报告各状态及动作访问分母、五次最低访问与 95% 门槛，也报告最终评价所遇未见、支持不足与回退频率。

**先验证跨年渠道，再比较折现。** 从同一期初资源与合同状态出发，只改变一项可行动作，以相同后续政策和逐事件配对冲击追踪次年及以后。分别检查年底现金、合同存续、谁实际续种和后续粮食；必要时一次只去掉现金结转或合同结转。若只改变当年账而不改变未来状态，停止在短视与固定策略比较。若有后续渠道，主折现率与较短、较长视野事先登记；7a 的 0.92 是历史参数，不自动成为现实财政折现率。所有策略在同一折现、同一完整窗口下评价，另报不折现累计和逐年分项。可在同一开发信息上用只看当期的对照区分折现视野与算法实现，不把不同训练折现率下各自得到的评分直接相减。终止支持应对各策略同时生效，并区分停发新承诺、已承诺待付和实际零支付；至少覆盖最后一笔承诺以及主要合同到期后的观测期，报告相对于始终不支持及持续支持的逐年差值。

## 四、长期验收与采用决策

在验证家庭递推、土地与财政账户后，先冻结主评价窗、停付窗、预算档、财政代价与最低有意义的增粮量。横轴是实际财政支付，纵轴是相对同种子无新增支持的实际收获增量；跨期折现值与不折现公斤、元并列，另列停付后的粮食、留任、换人续粮和恢复种粮，以及收入、租赁面积和亩均租金。逐预算档用相同评价种子计算配对差值和不确定性。少花钱又多产粮才是两轴同向改善；多产粮也多花钱则报告每新增公斤的额外财政成本，并按事先界定的可接受代价或预算下的粮食目标判断；不能靠调整评分权重宣称占优。只有实际支付可比或对照前沿能覆盖该支出水平，才比较等实付表现；不把相同预算上限当等实付。

| 最终独立评价 | 决策 |
|---|---|
| Q 只胜强固定，未胜同信息短视 | 状态适应有价值，未识别跨期增量；采用能达到目标的较简单规则。 |
| Q 只胜短视，未胜强固定 | 不推荐替代强固定。 |
| Q 在已冻结的目标下同时胜两者 | 仍须检查覆盖与回退、现金或合同跨年检验、财政–粮食前沿及停付实绩；全部支持时，才报告在所检验条件下存在额外跨期价值。综合分提升若只靠省钱，写清粮食没有增加或有所下降。 |
| 覆盖未达、证据缺失、两者均未胜，或结果对预定代价不稳健 | 保留固定与短视结果，报告具体失败或取舍，不为争取 Q 获胜追加不定向训练。 |
