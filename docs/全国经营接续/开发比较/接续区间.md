# 接续区间

严格接续指同一合成土地单元在相邻两期更换经营者且两期均种粮。年度汇总以 `strict_succession_lower_mu`、`strict_succession_upper_mu` 报告上期作物历史有账可推的部分。上下界均为物理亩，不是粮食播种亩次，也不是调查识别出的地块接续或统计置信区间。

核算固定两期的土地交付和经营者，不固定编号排序铺出的作物位置。对上一期经营者，若其经营面积为 `a0`、粮食物理亩为 `g0`，其中转给同一位本期经营者的面积为 `m`，则转出部分的上期粮食面积在 `[max(0, g0-(a0-m)), min(g0, m)]` 内。在本期每位经营者内，先分别加总各已知来源的下界和上界 `hL`、`hU`，再与本期粮食物理亩 `g` 求重叠：`[max(0, g-(a-hL)), min(g, hU)]`，其中 `a` 为本期经营面积。各经营者的上下界分别加总。当同一上期经营者的土地分给多户时，逐户极值可能不能同时达到，因此结果是保守外界。逐年用经营分配和经营者粮食总量计算新区间，不以排序作物位置作为区间输入；一致重编号不改变这些约束。

基期粮食物理亩沿用经营物理亩按粮经亩次份额折算的口径；后续用实种物理亩乘粮食亩次占粮经亩次的比例。没有逐季或逐地块的观测。基期作物缺项、无可跨期追踪的新进外池土地、以及上期由外池经营而本期回到样本的土地，均计入 `prior_crop_unknown_mu`；最后一类另列为其子项 `prior_external_pool_unknown_mu`。`grain_on_prior_unknown_lower_mu` 和 `grain_on_prior_unknown_upper_mu` 只界定本期在历史未知土地上种粮的面积，不推定上期未种粮，也不与严格接续区间的端点直接相加。

旧字段 `strict_synthetic_succession_mu` 及同一排序分配得到的作物交叉点值仅供诊断和复现，不作为正式接续结果或政府输入。原年度入口把新字段随汇总写入 `succession_summary.csv`；已有历史文件未追溯重算，不能从旧接续点反推新区间。土地、租金、生产、收入和财政账的原口径不变。

专项复核：`python -B -m pytest -q -p no:cacheprovider tests/test_empirical_succession.py`。附件反例的旧点 A/Z 为 4 和 0，两次核算的新区间均为 `[0, 4]`；第二年同地归还后的区间也一致。测试另核验正下界、续租、外池和原经济总量。
