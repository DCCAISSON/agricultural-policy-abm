## 一步与递推

**一步条件检验**以目标年的调查期初经营地和上一年调查粮经状态重新运行种植规划器，沿用本年度原账户的播前可用资金与家庭劳动，不发生新交易。这一步不预测期末产权或成交，不能用于五项联合放行。2011 年 558 户满足条件，B0 模拟粮食 4,130.39 亩次，调查 5,171.30；可用地没有直接消除实种误差。2015 年 464 户条件组，I 使粮食亩次缺口进一步扩大，C 没有改变 B0 的该期种植结果。[一步结果](一步对照/annual_development.csv)。

**多年递推**只在 2010 年初始化，之后分别按各自模拟结果更新。简单延续基准冻结上一期自身面积和作物；另报使用回看年度上年观察值的一步延续。它在数个年份的粮食亩次误差更低，但并不描述土地买卖、现金或产出的形成；2015 年递推兼种误差约 19.7 个百分点，高于 B0 的 15.1 个百分点。在四个筛选种子上，B0、I、C 的五项联合都为 7/20，不能用同一个通过数掩盖前述具体指标。原 20 种子只用于 B0 和简单延续全量比较；两个试验未达到目标，不进入 20 种子选定候选复验，不强行合并。历史五项 39/100 保留，不称独立验证。[递推表](递推对照/annual_development.csv) · [配对差及区间](递推对照/paired_deltas.csv) · [按预锁目标制作的回执](递推对照/development_receipt.json)。

没有真实同地跨年作物和交易对手，不得选取某个排序点作为真实接续。后续收到新版同信息比较源包并已复核，见[政府学习证据](政府学习证据.md)和[两地区试验](../共同预算/README.md)。经验环境仍无合格独立家庭面板，政策排序或 Q 训练未启动。

## 复算入口

```powershell
foreach ($v in ('B0','I','C')) {
    python -B -X utf8 -m scripts.run_empirical_succession $Project "../opening_$v" --variant $v --one-step --seeds 301 306 311 316
}
python -B -X utf8 -m scripts.compare_empirical_development $Project ../opening_results B0=../opening_B0 I=../opening_I C=../opening_C

```
