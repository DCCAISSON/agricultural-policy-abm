# 工作包 L：两套同户面积桥与成交诊断

**裁决：保留 B0，不启用 L。** 2015 年的主要偏差出现在当年经营规模形成，而不是同户期初面积已经明显偏小。B0 的外池供地上限确实限制了成交，但现有调查不能确定外池应增加多少供地、谁会释放这些土地，或哪些到期合同本应续签。容量消融是模型内部诊断，不把解除限制的成交量作为候选配置。

## 两套同户面积桥

两套口径均要求调查当年期初经营面积非负。历史口径保留期末严格正面积；第二套另纳入期末报告零、总播种同时报告零、且无任何正分项播种记录的家庭。零面积和正播种冲突不作有效零，缺项不填零。调查端保留上一年末、当年初、当年末及实际播种亩次；未调查的预撮合、合同到期、续租和交付分别留空。调查的经营亩、其中承包亩和全年播种亩次不互换。下表的物理面积差为模型减调查，模型为20个种子均值。

2015 年在同一批 451 户上，调查期初 4,194.00 亩，年内净增 1,057.10 亩。模型上一年末 4,175.99 亩，上一年合同到期后、当年撮合前为 4,115.20 亩；新交付净增 53.54 亩，年末实控 4,168.74 亩，实际种植物理面积 3,922.69 亩。含零口径则分别为调查期初 4,262.70 亩、模型上年末 4,318.21 亩、预撮合 4,234.70 亩、期末实控 4,321.00 亩、实际种植 4,074.15 亩。调查上年末与当年初在两边都可报告的同户上仍有差额，2015 年原口径为 −715.00 亩；不能将这个差额当作已知的期初归还或到期面积。

### 基期规模、尾部与去一

模型的2010年初始经营存量逐户等于调查2010年末经营亩，按这两个量分组所得结果完全一致。2015年原口径中，基期小于5亩、5至不足15亩、15亩及以上三组各有215、169、67户，模型分别多77.14亩、少378.84亩、少780.66亩。改用2011年调查期初：小于5亩的213户仍多111.33亩，5至不足15亩的156户仍少406.57亩；另有16户缺报调查基期，未挪入任何规模组。分位数、未合并的规模分组和转移表见附件。低于30户的规模组不展示量值。

去一只诊断影响，不从样本删户。先在每个种子上遍历删除同一户的调查和模型记录，取各自的最小与最大绝对相对误差，再对20个种子取平均。2015年原口径从20.61%变为16.13%至22.15%；含零口径从17.71%变为13.03%至19.35%。尾部确实影响合计，但去掉最有影响的一户，2015年两套口径的种子平均误差仍高于10%。这些去一范围不是抽样置信区间。

### 调查转包与其他增减

用《2009–2017农户调查问卷》的 NH2-6/NH2-7、NH2-8/NH2-10 与变量字典核对：area_in、area_de 是年内总增减，area_in1、area_de2 是其中转包。两子项同户可核记录数，2011至2015年分别为9、11、25、37、34户；前三年低于30户，附表不列金额。总项明确为零时，可另列逻辑上子项为零的口径，只在2012年增加1个同户记录，净额不变；其余空项仍未知。2014年同户净转包为431.70亩。

2015年双报的34户中，转包入359.40亩、转包出37.60亩，净转包321.80亩；其他增加15.40亩、其他减少24.70亩，合起来与该组存量增加312.50亩一致。在包含核实零的面积桥中，只有33户同时有可核租赁两边，调查净转包328.10亩，不能推广至全部463户。较大的年内存量差未必都是转包。只知总增减的家庭另列，其总增减不拆成净租赁；如既无同户两边转包、也无完整总增减，余额保留为未知。分别报告的转入户和转出户不可直接相减。

## 模型合同、重新出租与成交漏斗

B0合同均为一年。一年末实控可由初始经营存量与尚在该年有效的合同重建；下一年预撮合则去掉到期合同。逐户查验60,000户年，上一年末到合同刚到期之前、预撮合加净交付到当年末，两条账均在0.000001亩内闭合。2015年平均到期569.07亩，续签记录为零，当年新签579.19亩。在合成切片账上，重新出租的重叠部分中，171.19亩对应同一买方、145.23亩对应更换买方；这是重新竞租的合成账匹配，不是新旧真实地块或明确续约。外池供地没有可跟踪的原地块，匹配同一买卖双方只能给重合上界。

2015年全600户平均有208.15户下买单，买单共8,231.59亩，农户实际交付501.31亩，未满足7,730.28亩。模型清算后立即入当期实控账，没有独立的实地交接环节；全农户账中未见收到地且整户零播种，不能据此断定每块交付地都播种。另列原合成账的签后未播/租后未播分配值，其依赖模型的地块内作物分配，不当作实际逐地块播种。

市场前门槛由301号种子从年度执行入口核验，5年原始订单和合同均逐条复现。2015年，600户中178户下买单，30户所选生产面积为零，108户未过租入Logit，5户下一段面积受现金限制，5户在参考租金下的资金、回报及用工边界不容扩张，274户进入前述计算后未选扩张方案。这是互斥诊断顺序；零面积方案不等于观察到了家庭的主观经营意向，“未选扩张”也不等于三个方向中均存在可行扩张。只关租入Logit、保持实际当时的状态和随机数，给其中43户增加1,320.36亩买单；这是规划器复算，不是成交。

301号种子2015年178个买单中20个足额交付。对剩余买单，按实际清算顺序划分：37户同区没有卖单，70户无合成邻边，15户候选土地被前序买单耗尽，17户扣检索费后买卖报价不交，0户仅因地区共同租价区间没有交集而全部失去剩余可用边，19户归为部分交付或其余约束。当地匹配后再走外池；当容量用完时，后面的买单不会继续经过外池租价检查，不能从缺失分支反推它们都过价。无卖单不等于调查中无人愿意释放土地。

## 单一配对消融

原清算函数重放冻结订单、合成邻接和外池账，2011–2015年20个种子共100个种子年度逐笔复现归档合同，保持同一买单、区域价格、外池需求端和样本。只解除外池向家庭供地的容量上限，2015年外池交付由163.97亩增至5,513.61亩，平均净增5,349.64亩，种子范围2,857.16至7,681.15亩；当地合同与外池吸收家庭转出合同不变。结果显示容量在程序中实际约束成交，但没有调查依据为放宽规模定量。不要用上限解除结果替代真实供给，亦不据此改动空间、参考租价、合同期限或政府规则。
