## 当前生效规则与已知问题

| 运行规则 | 含义及尚未核实的部分 |
|---|---|
| 权利家庭比较自营收益、放弃的非农工资和出租机会，允许不经营 | 正账面剩余不保证续营；非农岗位上限和机会成本属于理论设定，未用调查识别具体家庭选择。 |
| 土地合同一年一签，权利人不变；土地释放后可能无人承接，成交后仍须满足实际播前现金和农忙用工 | 未成交地当年不回到原户自营，这是农时假设。续租不等于更换经营者；严格的粮食接续要求经营者改变且前后两年都种粮。 |
| 潜在承接者受现金与用工约束竞租，经营结果结转至下一年；本年已承租且年末现金低于周转门槛时，退出竞租 | 承接者不区分公司和合作社；未模拟再进入、信贷、真实交易网络或农机服务市场。 |
| 产后支持按核实粮食面积结算。承接播前支持只抵减实际粮食投入，不能先付地租 | 方案共用年度预算上限，实际支出不同。中间情景、相同承接者资格下，播前比产后每年多收867.62公斤粮、实际多支198.33元；不是等支出下的比较。 |
| 政府只读取上一年可观察的粮产、未成交率、承接种粮和财政执行，并在三项预设政策中选一项 | Q在三种独立环境中的奖励高于透明规则和固定产后支持，低于无新增专项和固定承接播前支持。该结论取决于预设奖励和所测理论环境，不能作为现实政策排序。 |
