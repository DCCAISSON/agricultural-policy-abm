# 土地经营接续：文献比较、参数证据与论文路线

## 1. 研究定位与版本

本文沿用 [项目科学问题 §1](../../SCIENTIFIC_QUESTION.md)，集中回答：**有限财政支持在什么条件下转化为持续的粮食生产能力？** 原经营者退出或缩减以后，土地成交只解决谁取得经营权；承接者能否在农时内筹齐投入并安排劳动，决定这块地是否继续种粮。把合同、实际生产、租金与支付逐块连到下一年，可以比较原经营者保留、新经营者接续、地租资本化、主体间再分配和传导削弱，而不预设哪一种占主导。

本文件对应 `land-succession-transmission-final-20261126`，继承 [土地接续冻结提交 25dae88d](https://github.com/DCCAISSON/agricultural-policy-abm/commit/25dae88d2727dc8f5c950fed534a65806bbfa648)。[F1 冻结提交 cc7eaabd](https://github.com/DCCAISSON/agricultural-policy-abm/commit/cc7eaabd2f4aa49686878afd5487ecd54b2c05ed) 和 600 户调查审计是经验参照，不是本模型的初始状态、校准样本或政府学习环境。本轮仍是单区域、非空间、两类抽象作物的理论实验。下文区分冻结版已有证据与本轮验收目标；后者须由对应版本的代码、测试和成品账确认。

### 工资审计：非农机会与农业雇工是两项不同的量

F1 冻结 `研究说明.md` 的 120 元/日是**外生给定的有酬农业雇工工资**，不是调查估计的非农净工资；F1 的非农收入另列，且不随当期农业工时调整。CFPS 2010 成人 `qh1×qh2` 给的是调查年度农业工日代理：按 `qh4` 无／有有酬非农就业报告分组，分别为 5,708/834 条个人记录，中位数 180/120 **日**、上四分位 275/200 **日**。不是日工资，也不是农忙期可兑现的工作天数。缺少与农时重叠的岗位、可用工时、净工资、交通和合同限制；不把“不知道”或跳题译成没有就业机会。

本模型工资 `w` 是非农机会的外生报酬，0–185 元/日为结构性区间，不再援引农业雇工 120 元/日作为数量依据。令 `L` 为可安排工日、`J` 为可兑现非农工日上限、`d` 为方案占用的农忙工日，种植方案放弃的非农收入为 `w × [min(L,J) − min(max(0,L−d),J)]`；结算只记实际可兑现的非农工日与工资，不将该差额重复扣进现金账。未挤掉非农工时，或没有可兑现的岗位时，机会成本可为零，但农业用工仍受工日约束。外部承接者的工日是可支配生产能力设定，不等于按该工资雇入。

**基线没有有酬农业雇工渠道。** 若将来单独研究季节雇工，须另有同地区、同农时或工序的实际雇工支出、雇工日、价格及可获得工日证据，核对零/缺失、时间与单位，再另设有酬工日和工资进入劳动与现金账。不能复用非农工资或把农业成本中的机械费折算成雇工。

## 4. 机制、对照和反证

沿用冻结版主体数、等面积地块、作物产价成本与农忙系数、初态范围和随机冲击。制度对照另列，不把它们写成观察到的现实行为：

- **合同与资格。** 一年期年度清算为基准；三年期在有效期内锁定经营权及合同租金，不重新竞租，不因持续履约重复给新增承接款。到期重新评估；提前终止、支付及责任在合同账上辨认。资格逐地块核对：直接换人、闲置后由新经营者取得与同一经营者续租分别标记；严格粮食接续是前后经营者不同且前后两期都实际种粮。成交后未播、改种不能计作接续。
- **统一金额与支付。** 年度事前公告的每块地保证上限为 `g=min(r×a,B/N,粮食播前投入/块)`（`r` 为名义元/亩、`a` 为每块亩数、`B` 为年度上限、`N` 为区域固定地块总数）。基准 48 块、4 亩、85 元/亩、7,200 元，因此单块至多 150 元，合 37.5 元/亩。报盘预期、给付承诺与核验后到账使用同一单位额度；不能在成交、申报或核验后按剩余申请数加价。缴租后、农资投入前才可抵减生产现金需求；产后不为播前融资；没有核实种粮则不形成最终支付。可用上限不等于实付，也不等于财政节余自动回流。
- **生产和再进入。** 权利家庭可自营、出租、闲置，也可承接别人的地；用同一现金与工日预算联合安排粮、经、闲。释放后未成交不回撤是基准；允许回撤时，在播种决策前给原权利户重新安排生产的机会，每块占用 120 元和 2 个农忙工日，仍比较可行性，不保证复耕。再进入基准关闭；开启时，退出年后再经过一个完整年份，允许以另列的外部资金补足至其合成初始现金并恢复报价资格。该资金不是专项补助；恢复报价、重新成交和实种分别判断。两项均为结构对照，不是经验估计。
- **财政比较。** P0 无专项（`none`）；P1 所有实种粮者播前（`grain_pre`）；P2 所有实种粮者产后（`grain_post`）；P3 合格新承接者播前（`takeover_pre`）；P4 合格新承接者产后（`takeover_post`）。A 逐年从同一 P0 期初状态分叉，固定合同、播前分配经营者（`assigned_operator`）、租金、资格、承诺金额和外生冲击，只改变到账时点；当期实种及后验经营状态不是固定项。B 采用同年度上限，允许供求、报价、租金和生产内生变化，实付可不同。两种比较不能互称。把同一承诺额与实际付款额同时报告；未播种组可能实付为零。
- **敏感性。** 保留搜寻失败率 0.08/0.48、承接资金乘数 1.00/0.56、农忙劳动乘数 1.00/0.60 的预定 2×2×2。另分开改搜寻与费用、保留报价与启动成本、非农工资倍数（0.7/1.0/1.3）、合同期限、承接者数量、回撤与资源恢复；现金和退出状态采用独立开关。名义支持 60/85/120 元/亩在基准预算下对应的实际额度**均为 150 元/块**；这一组检验预算上限是否主导，不识别有效补助额的响应。报告有效额的敏感性应使用事前设定、确实改变 `g` 的预算对照，不得事后调价。各主比较至少 100 个配对种子，机制至少 50 个；按完整路径作统计单位，再报配对区间、分位数和逐年结果。

| 事前命题 | 支持它的可观察条件 | 反证或竞争解释 |
|---|---|---|
| H1. 播前流动性是成交后增粮的渠道。 | 固定合同、资格和承诺额时，到账提前在现金临界、劳动可行的地块提高播种；现金充足或劳动不可行时差异收窄。 | 固定条件下无差异，或优势仅在内生市场出现；前者表明本情景未约束，后者指向报价、成交或资格组成。 |
| H2. 承接支持改变生产承担者，不等于增加全部粮食。 | 比较 P3/P1、P4/P2：用换人且持续种粮的亩数、原户续种亩数、区域粮食公斤和实付分别度量。 | 租入粮地增加仅来自同一承租者续期，严格接续不变；或新增接续被原经营者减种抵消。不能把第一种写成换人接续。 |
| H3. 租金和现金／劳动约束会削弱传导。 | 同地块同口径租金与市场成交面积分开；同地租价上涨与对手报价和权利人租金收入联动；未成交、成交后未播与非粮各有可回加面积。 | 总租金增而单位租金不增，仅为数量或构成变化；粮食未响应却无价格变化时转查投入与劳动。比率以非零新增支出为分母，零分母单列；未解释余额不强行报货币归宿。 |
| H4. 合同及资金状态改变停付后的持续性，方向待检验。 | 一年与三年合同都在固定追踪队列按停付第1/2/3年比较同一经营者、继续种粮、改种、闲置、收获、利润和现金；分别关闭现金结转和退出状态反馈。 | 续约或锁定经营者增加但粮食不维持，说明权利稳定不是生产稳定；如优势随停付消失或仅见于退出重置，不宣称形成了持续能力。 |
| H5. 有限期动态规则相对固定策略的改进取决于可观察状态。 | 五个固定动作、透明规则和冻结后的 Q 在同预算、同种子、同信息下比较。政府仅见上年区域粮食、释放未成交与严格接续、财政执行和剩余期限，奖励分别计粮食、接续和支出；报告各组成及不同权重。 | 只超过部分策略、只在训练环境占优、或换权重后反转，都不支持普遍改进；政府不接触单户现金、潜在生产率、未来天气或反事实结果。 |

## 5. 可用旧证据和本轮验收

冻结版程序入口 `core/land_succession.py::Succession.step`、`modules/land_clearing_house.py::clear_area_orders` 和 `scripts/run_land_succession.py`；旧结果目录 `results/experiments/land_succession_theory_20261126`。其 `ledger_verification.json` 核对 17,088 个评价年度与 820,224 条地块账。旧 `mechanism_contrasts.csv` 的中间情景中，同为承接者支持，播前比产后平均多 867.62 公斤/年（24 条配对世界线，95% 区间 525.96–1,209.29 公斤/年），同时实付相差 198.33 元/年。旧比较**既未固定合同和承诺额，又在阶段间重算金额**，只能作为上一版机制线索，不称为纯到账时点效应。旧 `paired_effects.csv` 的政府只学三个动作，在三类留出情景均未胜无专项及固定承接播前；不外推到本轮五动作。旧版租入地种粮指标包含按前版定义的承接，不重贴严格接续标签。

本轮验证入口是 `core/land_succession.py`、联合配置 `core/succession_allocation.py`、`scripts/run_land_succession.py`、`scripts/succession_analysis.py`、`scripts/succession_q.py` 与 `tests/test_land_succession_transmission.py`。本次文档核对在当前工作树单独执行 `python -B -m pytest -q -p no:cacheprovider tests/test_land_succession_transmission.py`，27 项通过。正式运行仍需按成品账复核：地块、合同、经营者、租金双边、投入、工日、实际付款与年度账一致；零预算五政策同基准；紧预算不超支且不重定价；固定合同播前/产后只改现金时序；1/3 年期限与到期、续租和无重复资格；恢复与退出再进入有对应资源账；无承接者、无释放、极端搜寻/现金/劳动；地块正序、逆序和随机置换不改经济结果。模型内检验是复现和反证手段，不是经验拟合或政策识别。
