## 与土地接续模型的关系

| 参考及官方入口 | 对本模型的用途 |
|---|---|
| [Tian、Holland、Brown（2016）](https://doi.org/10.1016/j.agsy.2016.06.005) | 区分生产者支持与土地出租激励。本文的承接者播前投入支持并非该文给出让者的长租补助。 |
| [Happe、Kellermann、Balmann（2006）](https://www.ecologyandsociety.org/vol11/iss1/art49/)；[AgriPoliS 手册](https://www.agripolis.org/agripolis/manual) | 异质经营者竞租和跨年结构调整。未移植该模型的参数、生产系统或组织定义。 |
| [de Janvry、Fafchamps、Sadoulet（1991）](https://doi.org/10.2307/2234892) | 当劳动与产品交易不完全时，家庭经营与非农时间不能简单分开。非农工资不作为一刀切的农业劳动成本。 |
| [Vinyals 等（2023）](https://doi.org/10.3389/fams.2023.1000785) | 机构在农业技术扩散仿真中选择政策的先例。本文政府学习的是土地接续环境中的支持规则，不比较技术扩散。 |
| [Njiru 等（2025）](https://doi.org/10.22434/ifamr.1126) | AgriPoliS 已有学习型农场竞价。本模型只有政府学习，经营者不学习。 |
| [Grimm 等（2020）](https://doi.org/10.18564/jasss.4259) | 按 ODD 描述初态、调度、规则和实施验证。 |

收录文献不等于将其中的机制或参数移植进模型。当前检验的是：合同成交与实际播种之间的资源约束，是否通过经营主体周转能力改变财政支持的生产接续效果。
