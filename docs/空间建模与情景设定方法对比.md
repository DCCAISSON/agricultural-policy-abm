## 🌾 我们模型的做法（建议方案）

### 1. 空间分布方案

由于我们的研究聚焦**粮食补贴政策效果**，空间建模的重要性相对较低。
建议采用**简化的区域分类**而非真实地理坐标：

```
研究问题 → 社会发展情景(SSP) → 政策效果评估
         ↓
    空间异质性（可选）：通过参数分布体现，而非真实地理
```

**方案A：无空间异质性（当前）**
- Agent随机放置
- 异质性通过属性分布体现（年龄、土地、风险偏好）
- 优点：简单、聚焦核心问题
- 适用：如果研究不涉及区域比较

**方案B：简化区域分类**
- 将Agent分为2-3类区域（主产区、兼业区、边缘区）
- 每类区域有不同参数（土地禀赋、市场距离等）
- 优点：可分析区域异质性
- 适用：如果需要比较不同类型农村

### 2. 情景设定方法

使用 **SSP社会发展情景** 作为背景框架：

| SSP | 名称 | 核心特征 |
|-----|------|---------|
| SSP1 | 可持续发展 | 高技术、城乡融合、政策高效 |
| SSP2 | 中间道路 | 延续现状趋势 |
| SSP3 | 区域竞争 | 碎片化、低效率、青年流失 |
| SSP4 | 不平等 | 大资本进入、小农边缘化 |
| SSP5 | 高增长 | 快速城镇化、农业转型快 |

**SSP参数覆盖（见 `config/ssp_scenarios.py`）：**
- 人口结构：城镇化率、青年务农率
- 经济发展：GDP增长、非农工资
- 技术进步：机械化率、劳动生产率
- 土地流转：摩擦系数、规模化程度
- 政策效率：财政能力、瞄准精度

### 3. 政策评估框架

```
基准配置(baseline) × SSP情景(5个) × 补贴率(7档) = 35组实验
```

**补贴率设置（见 `analysis/grain_subsidy_evaluator.py`）：**
- 0元/亩（取消补贴）
- 100元/亩（低补贴）
- 200元/亩（基准/当前水平）
- 350元/亩（中等）
- 500元/亩（高）
- 800元/亩（极高）
- 规模加成（200+50%加成）

## 📋 关键对比

| 维度 | 参考项目 | 我们的模型 |
|------|---------|-----------|
| **研究问题** | 气候风险对供应链的影响 | 粮食补贴政策效果 |
| **空间来源** | GeoTIFF栅格（真实地理） | 随机/参数分布（简化） |
| **情景框架** | RCP气候情景 | SSP社会发展情景 |
| **外部驱动** | 洪水深度地图 | 社会经济参数 |
| **Agent位置** | 真实经纬度 | 随机或区域分类 |
| **异质性来源** | 空间位置的灾害暴露度 | Agent属性分布 |

## ✅ 建议的研究设计

```
        SSP1    SSP2    SSP3    SSP4    SSP5
无补贴    ✓       ✓       ✓       ✓       ✓

极高      ✓       ✓       ✓       ✓       ✓
规模加成  ✓       ✓       ✓       ✓       ✓
```

### 评估指标
1. **粮食安全**：产量、面积、单产
2. **农民福利**：收入、基尼系数
3. **结构变化**：流转率、青年占比
4. **财政效率**：补贴成本/产量

### 分析问题
1. 不同SSP情景下，最优补贴率是多少？
2. 补贴政策对不同类型农户的影响差异？
3. 政策执行效率如何影响补贴效果？
4. 规模加成政策是否优于普惠补贴？
