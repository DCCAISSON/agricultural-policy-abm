# 列映射配置说明

## 概述

本文档说明 `config/calibration_config.yaml` 中列映射配置的含义，以及这些列在CLES数据文件中的实际含义。

## 农户面板列映射

### 1. initial_capital (初始资本)

- **配置列名**: `e412`
- **CLES数据含义**: "创业初始投入资金（万元）"
- **模型用途**: 用于初始化农户的初始资本，影响农户的投资能力和风险承受能力
- **数据说明**: 
  - 单位：万元
  - 仅适用于创业户
  - 如果农户不是创业户，此值可能为空
- **建议处理**: 
  - 对于非创业户，可以使用其他资产指标（如 `e410`: "当前资产（万元）"）作为替代
  - 或者使用收入相关指标进行估算

### 2. farming_ability (耕作能力)

- **配置列名**: `a206a1`
- **CLES数据含义**: "文化程度（在校几年）1"（户主的教育程度）
- **模型用途**: 用于表示农户的耕作技能和学习能力
- **数据说明**: 
  - 表示户主在校年数
  - 通常范围：0-20年
- **建议处理**: 
  - 需要标准化到0-1范围或使用其他能力指标
  - 可以考虑结合 `a209a1`: "是否受过农业技术教育或培训1" 来综合评估
- **替代选项**:
  - `a209a1`: "是否受过农业技术教育或培训1" (0/1)
  - `a208a1`: "是否受过非农职业教育或培训1" (0/1)

### 3. farmland_area (土地面积)

- **配置列名**: `c107a`
- **CLES数据含义**: "耕地经营的总面积（亩）"
- **模型用途**: 用于初始化农户经营的土地面积
- **数据说明**: 
  - 单位：亩
  - 包括承包地和转入地
  - 这是农户实际经营的总面积
- **数据质量**: 此列通常有较好的数据完整性

### 4. risk_aversion (风险厌恶)

- **配置列名**: `i701`
- **CLES数据含义**: "风险偏好"
- **模型用途**: 用于表示农户的风险态度，影响决策行为
- **数据说明**: 
  - 可能是分类变量（如1-5的评分）
  - 需要查看具体的数据编码规则
- **建议处理**: 
  - 如果是分类变量，需要转换为数值型
  - 可能需要反向编码（偏好风险 = 低风险厌恶）

### 5. social_degree (社交网络度数)

- **配置列名**: `j204`
- **CLES数据含义**: "您的手机联系人数量"
- **模型用途**: 用于表示农户的社会网络连接度
- **数据说明**: 
  - 表示手机联系人数量
  - 可以作为社交网络规模的代理变量
- **建议处理**: 
  - 可能需要标准化或对数变换
  - 可以考虑结合其他社交网络指标（如合作社参与度）

## 数据文件格式说明

### 文件结构

CLES数据文件通常有以下特点：

1. **第一行**: 包含中文变量描述（元数据）
2. **第二行开始**: 实际数据
3. **编码**: 使用 `gb18030` 编码（中文国家标准）

### 读取方式

```python
# Excel文件
df = pd.read_excel('file.xlsx', sheet_name=0)

# CSV文件
df = pd.read_csv('file.csv', encoding='gb18030', dtype=str)
# 第一行是元数据，需要跳过
data_df = df.iloc[1:].reset_index(drop=True)
```

4. 检查数据完整性（缺失值、异常值）

## 常见问题

### Q1: 某些列在数据文件中不存在

**A**: 使用 `scripts/fix_column_mapping.py --recommend` 获取建议的列名，然后手动更新配置文件。

### Q2: 数据单位不匹配

**A**: 在数据预处理阶段进行单位转换。例如：
- `e412` 的单位是"万元"，模型可能需要"元"，需要乘以10000
- `c107a` 的单位是"亩"，如果模型使用"公顷"，需要除以15

### Q3: 缺失值处理

**A**: 在 `analysis/empirical_calibration.py` 中，`_extract_series` 方法会自动处理缺失值（使用 `dropna()`）。对于关键变量，可能需要：
- 使用中位数或均值填充
- 使用回归方法预测
- 排除缺失值过多的观测

### Q4: 变量需要转换

**A**: 在 `EmpiricalMomentLoader` 中添加转换逻辑，例如：
- 标准化（z-score）
- 对数变换
- 分类变量编码
