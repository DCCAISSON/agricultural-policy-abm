# Mesa浏览器可视化使用指南

## 简介

基于Mesa框架的交互式浏览器可视化，可以实时观察模型运行过程，包括：
- 农户位置和生计类型（颜色编码）
- 实时图表：生计类型演化、收入分布、基尼系数、市场价格
- 可调参数：农户数量、模拟步数、随机种子

---

## 快速开始

### 1. 启动服务器

```bash
python run_mesa_visualization.py
```

或指定端口：

```bash
python run_mesa_visualization.py --port 8521
```

### 2. 打开浏览器

访问：`http://127.0.0.1:8521`

### 3. 调整参数并运行

在浏览器中：
1. 调整"农户数量"滑块（50-500）
2. 调整"模拟步数"滑块（10-200）
3. 设置"随机种子"（可选）
4. 点击"Reset"重置模型
5. 点击"Run"开始运行

## 可视化说明

### 网格视图（左上）
- **蓝色圆圈**：Pure_Farmer（纯农户）
- **橙色圆圈**：Pluriactive（兼业农户）
- **绿色圆圈**：Non_Farmer（非农户）
- **圆圈大小**：表示收入水平（收入越高，圆圈越大）

### 图表视图

#### 1. 生计类型演化（右上）
显示三种生计类型的数量随时间变化

#### 2. 收入分布（中上）
显示平均收入和中位数收入随时间变化

#### 3. 基尼系数（中下）
显示收入不平等程度（0-1，越高越不平等）

#### 4. 市场价格（右下）
显示粮食价格、经济作物价格、日工资随时间变化

## 功能特点

### ✅ 实时可视化
- 模型运行过程中实时更新
- 可以暂停、继续、重置

### ✅ 交互式参数调整
- 无需修改代码即可调整参数
- 立即看到参数变化的影响

### ✅ 多指标监控
- 同时监控多个关键指标
- 便于发现模型异常

---

## 注意事项

1. **性能**：农户数量>300时可能较慢，建议先用小规模测试
2. **浏览器**：推荐使用Chrome或Firefox
3. **端口冲突**：如果8521端口被占用，使用`--port`指定其他端口

---

## 故障排除

### 问题1：无法访问
- 检查防火墙设置
- 确认端口未被占用
- 尝试使用`127.0.0.1`而不是`localhost`

### 问题2：图表不更新
- 刷新浏览器页面
- 检查控制台是否有错误信息

### 问题3：模型运行很慢
- 减少农户数量
- 减少模拟步数
- 关闭其他占用资源的程序
