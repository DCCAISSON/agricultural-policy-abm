# 完整参数校准使用指南

## 概述

本指南说明如何使用新实现的完整参数校准系统，包括从CLES数据估计生产函数参数和从文献获取其他参数。

## 新增的校准参数

### 1. 生产函数弹性参数（从CLES数据估计）

- **α (土地弹性)**: 土地投入对产出的弹性
- **β (劳动弹性)**: 劳动投入对产出的弹性  
- **γ (资本弹性)**: 资本投入对产出的弹性

**数据来源**: CLES数据的e1**系列
- `e102a*`: 种植面积（土地投入）
- `e103a*`: 总产量（产出）
- `e112a*`: 自投工日（劳动投入）
- `e113a*`: 雇工费用（劳动投入）
- `e107a*-e111a*, e115a*`: 各种费用（资本投入）

### 2. 气候冲击参数（从CLES数据估计）

- **μ_climate**: 气候冲击均值
- **σ_climate**: 气候冲击标准差

**估计方法**: 从产量波动中分离气候冲击影响

### 3. 前景理论参数（从文献获取）

- **loss_aversion_lambda**: 损失厌恶系数（均值3.0）
- **value_function_curvature**: 价值函数曲率（均值0.55）
- **probability_weighting**: 概率权重参数（均值0.7）

**数据来源**: Kahneman & Tversky (1979) 及中国农户行为研究

### 4. 社会网络参数（从文献获取）

- **small_world_k**: 小世界网络邻居数（6）
- **small_world_p**: 重连概率（0.1）

**数据来源**: Watts & Strogatz (1998) 及中国农村社会网络研究

### 5. 市场机制参数（从文献获取）

- **wage_adjustment_elasticity**: 工资调整弹性（0.05）
- **price_adjustment_speed**: 价格调整速度（0.2）
- **rent_growth_rate**: 租金增长率（0.03）

**数据来源**: 农业经济学理论及中国农业市场研究

### 6. 技术扩散参数（从文献获取）

- **info_transmission_rate**: 信息传播概率（0.12）
- **adoption_threshold_mean**: 技术采纳阈值均值（0.4）

**数据来源**: Rogers (2003) 及中国农业技术推广研究

### 7. AI冲击参数（从文献获取）

- **ai_tfp_enhancement**: AI对TFP的增强效应
- **ai_labor_substitution**: AI对劳动的替代参数
- **ai_input_saving**: AI对投入品的节约参数
- **ai_job_displacement**: AI对非农就业的挤出效应

**数据来源**: 麦肯锡全球研究院报告（2023）及AI影响研究

## 使用方法

### 方法1: 完整校准（推荐）

一次性完成所有参数的校准：

```bash
python scripts/complete_calibration.py \
    --data-dir "校准用数据源" \
    --year 2020 \
    --output "results/complete_calibrated_parameters.json" \
    --update-config
```

**输出**:
- `results/complete_calibrated_parameters.json`: 完整校准结果
- 如果使用 `--update-config`，会更新 `config/calibrated_params.json`

### 方法2: 分步校准

#### 步骤1: 仅估计生产函数参数

```bash
python analysis/production_function_calibration.py \
    --data-dir "校准用数据源" \
    --year 2020 \
    --output "results/production_function_params.json"
```

**输出**: `results/production_function_params.json`

#### 步骤2: 仅获取文献参数

```bash
python analysis/literature_based_parameters.py \
    --output "results/literature_parameters.json"
```

**输出**: `results/literature_parameters.json`

#### 步骤3: 合并参数

使用 `scripts/complete_calibration.py` 的合并功能，或手动合并JSON文件。

## 参数说明

### 生产函数参数估计方法

使用Cobb-Douglas生产函数：

```
Y = TFP * A^α * L^β * K^γ * (1 + ε_climate)
```

对数线性化后使用OLS回归：

```
ln(Y) = ln(TFP) + α*ln(A) + β*ln(L) + γ*ln(K) + ε
```

**数据要求**:
- 至少50个有效观测值
- 面积、产量、劳动、资本投入均为正值

**验证指标**:
- R² > 0.5（模型拟合度）
- α + β + γ ≈ 1（规模报酬接近常数）
- 所有参数p-value < 0.05（统计显著性）

### 文献参数来源

所有文献参数均基于权威研究和官方资料：

1. **前景理论参数**: Kahneman & Tversky (1979) 经典研究，结合中国农户行为研究调整
2. **社会网络参数**: Watts & Strogatz (1998) 小世界网络理论，结合中国农村社会网络调查
3. **气候冲击参数**: Ortiz-Bobea et al. (2020) 全球农业TFP研究，结合中国农业统计年鉴
4. **AI冲击参数**: 麦肯锡全球研究院（2023）报告，结合中国AI应用案例
5. **市场机制参数**: 农业经济学理论，结合中国农业市场实证研究
6. **技术扩散参数**: Rogers (2003) 创新扩散理论，结合中国农业技术推广实践

1. **生产函数参数** → 用于计算产量

## 常见问题

### Q1: 生产函数参数估计失败

**原因**: 数据不足或数据质量问题

**解决**:
1. 检查数据文件是否存在
2. 检查数据完整性（缺失值、异常值）
3. 尝试使用不同年份的数据
4. 如果数据不足，使用默认值（α=0.4, β=0.3, γ=0.2）

### Q2: 文献参数是否需要调整

**建议**: 
- 文献参数基于权威研究，通常不需要调整
- 如果您的模型有特殊需求，可以手动修改 `analysis/literature_based_parameters.py`
- 修改后重新运行校准脚本

### Q3: 如何更新参数

**方法**:
1. 重新运行完整校准脚本
2. 或手动编辑 `results/complete_calibrated_parameters.json`
3. 使用 `--update-config` 更新配置文件
