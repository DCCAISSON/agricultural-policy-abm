# 快速运行检查指南

## 一、运行模型

### 方法1：命令行运行（推荐）

在项目根目录打开命令行（CMD或PowerShell），运行：

```bash
python runner.py --mode single --steps 50 --seed 42
```

**参数说明**：
- `--mode single`: 单次仿真
- `--steps 50`: 运行50个时间步
- `--seed 42`: 固定随机种子（确保可复现）

### 方法2：交互式运行

```bash
python runner.py
```

然后选择运行模式（输入 `1` 选择单次仿真）

## 二、查看运行结果

### 2.1 结果文件位置

运行完成后，结果保存在：
```
results/single_runs/YYYY-MM-DD_HH-MM/
```

**主要文件**：
- `model_data.csv`: 模型层面的时间序列数据
- `agent_data.csv`: 智能体层面的数据
- `figures/`: 自动生成的可视化图表

### 2.2 关键检查指标

运行过程中会每5步输出一次信息，**重点关注**：

```
Step 0: Pure Farmers = 91, ...
Step 5: Pure Farmers = 87, ...
Step 10: Pure Farmers = 105, ...
...
```

**✅ 修复成功的标志**：
- Pure_Farmer 数量**减少**（从91减少到20-30）
- Pluriactive 数量**增加**
- Non_Farmer 数量**增加**

**❌ 如果问题仍然存在**：
- Pure_Farmer 数量**增加**（如从91增加到176）
- Pluriactive 数量**减少**
- Non_Farmer 数量**不变化**

- `gini_coefficient.png`: 基尼系数图

### 3.2 使用Python快速分析

创建文件 `quick_check.py`：

```python
import pandas as pd
import matplotlib.pyplot as plt

# 替换为实际路径
model_data = pd.read_csv('results/single_runs/最新日期/model_data.csv')

print("=== 生计类型演化检查 ===")
print(f"初始: Pure={model_data['Pure_Farmer'].iloc[0]}, "
      f"Pluriactive={model_data['Pluriactive'].iloc[0]}, "
      f"Non_Farmer={model_data['Non_Farmer'].iloc[0]}")

print(f"最终: Pure={model_data['Pure_Farmer'].iloc[-1]}, "
      f"Pluriactive={model_data['Pluriactive'].iloc[-1]}, "
      f"Non_Farmer={model_data['Non_Farmer'].iloc[-1]}")

print(f"\n变化: Pure={model_data['Pure_Farmer'].iloc[-1] - model_data['Pure_Farmer'].iloc[0]:.0f}, "
      f"Pluriactive={model_data['Pluriactive'].iloc[-1] - model_data['Pluriactive'].iloc[0]:.0f}, "
      f"Non_Farmer={model_data['Non_Farmer'].iloc[-1] - model_data['Non_Farmer'].iloc[0]:.0f}")

# 绘制演化图
plt.figure(figsize=(10, 6))
plt.plot(model_data['Step'], model_data['Pure_Farmer'], label='Pure_Farmer', linewidth=2)
plt.plot(model_data['Step'], model_data['Pluriactive'], label='Pluriactive', linewidth=2)
plt.plot(model_data['Step'], model_data['Non_Farmer'], label='Non_Farmer', linewidth=2)
plt.xlabel('时间步')
plt.ylabel('农户数量')
plt.title('生计类型演化')
plt.legend()
plt.grid(True)
plt.savefig('livelihood_check.png', dpi=150)
print("\n图表已保存为 livelihood_check.png")
```

运行：
```bash
python quick_check.py
```

## 五、问题排查

### 如果Pure_Farmer仍然增加

**检查点**：
1. 检查农业收入占比计算是否正确
2. 检查劳动力分配是否正确（Pure_Farmer应该是60%/40%）
3. 检查切换到Pure_Farmer的概率是否足够低（3%-15%）

**调试方法**：
查看运行日志中的切换信息，例如：
```
农户farmer_121生计策略切换: PURE_FARMER, 农业收入占比: 0.838, ...
```

### 如果Non_Farmer仍然不增加

**检查点**：
1. 检查非农收入是否足够（>8000元）
2. 检查非农就业机会是否充足
3. 检查切换到Non_Farmer的概率是否足够高（90%）

## 六、快速检查清单

运行模型后，检查以下指标：

- [ ] Pure_Farmer数量减少（从91减少到20-30）
- [ ] Pluriactive数量增加（从175增加到200-240）
- [ ] Non_Farmer数量增加（从30增加到50-80）
- [ ] 企业经营土地总面积增加（从14增加到100-200以上）
- [ ] 收入分布更合理
- [ ] 基尼系数在合理范围内（0.28-0.35）
