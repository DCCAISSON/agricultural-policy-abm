## 摘要

公共财政支持进入乡村食物系统后，能否转化为持续的粮食生产能力，抑或通过土地竞价资本化为地租并改变主体间收入分配，取决于补贴制度的权利归属、资金可替代性与基层生产组织条件。本文基于全国农村固定观察点（NFPS）600 户固定农户队列（5,277.5 物理亩耕地），在 Mesa 框架下构建包含异质农户、家庭农场、农民合作社、农业企业与唯一强化学习中央政府的多主体动态模拟系统（V2.0）。结果表明：（1）锁定既定租约时，播前生产者直补比产后补贴多产粮 17.61 吨；对称分解揭示适度规模现金补贴的纯价格地租资本化率达 38.10%（同地块亩租上涨 81.66 元/亩）；（2）生产托管农机补助在等实支口径下增粮效率为规模现金补贴的 5.0 倍（52.85 公斤/百元），纯价格资本化率仅 6.54%—6.73%；（3）在无跨期服务沉淀与无跨年预算结转条件下，`Gov-RL` 相对 `Uniform-Fixed` 多产粮 53.64 吨并节支 7.13 万元，但与同信息短视 `Myopic` 完全一致（差值 0.00 吨）。
