# Mesa Agri-ABM V2.1 跨期制度耦合、信息不对称识别与政府强化学习必要性深化报告

## 一、升级背景与三大真实跨期制度考证结论

围绕 V2.0 中暴露的三项核心科学追问——① 2011—2015 年五年动态递推中农户参与率偏高（`528.45` 户 vs 调查 `445` 户）；② 默认单年租约、无服务沉淀设定下 `Gov-RL` 与同信息短视 `Myopic` 完全重合（差值 `0.00` 吨）；③ 候选制度调节条件（村集体协调、订单粮食）及自然—社会耦合信息不对称下的**逆向选择（Adverse Selection）与道德风险（Moral Hazard）**尚未显式进入主模型——本轮在不触碰冻结 V2.0（标签 `mesa-agri-abm-20261127-v2`，提交 `504c4bf`）任何默认行为与历史结果的前提下，在 `mesa_agri_abm/` 中完成了基于中国真实法规与微观数据的 `V2.1`（`upgraded_v2_1_design()`）深化实现。

### 1. 对中国三项跨期现实制度的考证与落地方案
1. **流转合同期限结构：并非单一短租或单一长租，而是“双轨异质契约期限”**
   - 政策与文献依据：《农村土地承包法》（2018 修正）、《农村土地经营权流转管理办法》（农业农村部令 2021 年第 1 号）以及罗必良（2017）、邹宝玲等（2016）、Cao et al.（2022，*Land*）。
   - 现实结构与建模：熟人小农间流转以 **1 年期滚动口头/短期契约**为主；家庭农场与合作社因农机与田间整理投入普遍签订 **3 年期书面契约**；农业龙头企业普遍签订 **4 年及以上长期契约**。模型支持 `1` 年短租、`3` 年长租与 `1/3/4` 年双轨契约三种制度实验。
2. **财政预算跨年规则：“当年预算硬清零不囤积 + 跨年因素法绩效调节挂钩”**
   - 政策依据：《中华人民共和国预算法》（第 12、42 条）、《国务院关于印发推进财政资金统筹使用方案的通知》（`国发〔2015〕35号`）、财政部与农业农村部《农业相关转移支付资金管理办法》（`财农〔2023〕11号`）及《耕地建设与利用资金管理办法》（`财农〔2023〕12号`）。
   - 现实结构与建模：**年度财政预算当年严格核销清零、绝不形成跨年资金池囤积**（验证了此前“年度预算不跨年结转”判断的合理性）；但上下级转移支付分配实行**“因素法 + 绩效评价结果与下年度资金分配挂钩（奖优罚劣）”**，上年度种粮保留率高、闲置率与违规偏离率低的区域在下年度获得 `[0.82, 1.18]` 区间内的预算切块正向调节（全国总额仍严格锁定 `150,000` 元/年）。
3. **农业社会化服务（生产托管）跨期能力沉淀与成熟退坡机制**
   - 政策与文献依据：`农经发〔2017〕19号`、`农办经〔2019〕19号`、`农经发〔2021〕2号`、罗必良（2017，《中国农村经济》）与江帆等（2024，《自然资源学报》）。
   - 现实结构与建模：连续实施生产托管补助会培育区域农机服务网络成熟度 $K_{r,t} \in [0, 1]$（大马力农机摊销、县乡村三级服务网点标准化与连片路径降本，最高降低 `24%` 作业费并带来 `3.2%` 技术效率提升）；在培育初期（$K_{r,t}$ 较低时）高峰期作业覆盖受限，而当服务市场高度成熟（$K_{r,t} > 0.55$）后，继续全额补贴托管会出现边际外替代效应，触发政策文件明确要求的**“连续扶持退坡机制”**。

### 2. 环境 B：完全信息下的纯跨期沉淀对照（`intertemporal_v2_1`，48 个留出种子）
