本文档严格遵循 Grimm 等（2020）与 Müller 等（2013）的 **ODD+D（Overview, Design Concepts, Details + Decision）** 国际多主体建模规范，逐项交代 `mesa_agri_abm/`（`Mesa 2.3.2`）的主体结构、观测边界、数学规划方程、年度调度时序与参数证据分级。

## 1. Overview（模型总览）

### 1.1 Purpose（研究目的）
模型用于研究有限公共财政支持进入中国农村农业经营体系后，如何经过异质农户与新型农业经营主体的种植选择、口粮自留、农机服务采购和省内土地经营权竞争，分化为**原有粮食生产保留、经营者更替后的粮食接续、土地租金资本化、主体间收入再分配或未实现的传导损耗**，并检验唯一强化学习中央政府在滞后公共汇总信息与共同预算硬约束下的跨期政策配置表现。

### 1.2 Entities, State Variables, and Scales（实体、状态变量与尺度）
模型以 `1` 个农业生产年度为基本时间步（主实验连续运行 `8` 年；停补持续性实验在 `V2.0` 主表分叉追踪第 `8–9` 年，在 `V2.2` 统一于第 `6` 年末停补并分叉追踪第 `7–8` 年），空间覆盖东、中、西、东北四个政策区及下属省级样本子市场：

1. **调查农户（`HouseholdMesaAgent`，600 户）**：初始化自 NFPS 2010 年固定队列（脱敏编号 `H0000..H0599`），状态包含物理承包/经营面积、可流转地权面积、家庭人口与农业劳动力、农闲保留工日与非农竞争窗口工日、外生非农日工资、基期口粮需求 `subsistence_grain_kg`（实测自 `foodc`）、复种上限 `mci`、具名粮食作物权重（小麦/稻谷/玉米/大豆/其他）、春耕营运资金 `working_cap`、家庭储蓄 `wealth` 及种粮参考份额 `ref_grain_share`。
2. **三类合成新型农业经营主体（`ScaleOrgMesaAgent`，共 `41` 个，与 600 调查户严格分账）**：
   - `FamilyFarmAgent`（商业化家庭农场，23 个）：具 2 名家庭全职农业劳力，可雇工与购农机服务，最大化家庭净收益；
   - `CooperativeAgent`（农民合作社，15 个）：分布于可流转面积 `>= 90` 亩的子市场，零无偿家庭劳力，具农机连片协调与农资集采成本折减，承担合作社管理费用，不虚构未观测的社员返利契约；
   - `AgriCompanyAgent`（农业企业，3 个）：分布于东北等 `>= 200` 亩大宗粮食子市场，100% 付费雇工并承担企业管理间接费，连续两年资本净回报低于阈值（`-5%`）或流动性枯竭时内生退出市场。三类主体均**不赋予任何人为单产技术加成**。
3. **持续存在的合成土地经营单元（`ParcelBlueprint` + `LeaseContractV2`，共 `1,831` 块、`5,277.5` 物理亩）**：保留真实省级编码与精确物理面积（其中 `4,009.2` 亩具可流转承包权），逐年分离记录权利人（`owner`）、上期经营者（`last_operator`）、当期实际经营者（`operator`）、租赁合同起止年与成交亩租、实种作物与收获产量。网格坐标 `(grid_x, grid_y)` 明确标记为 `is_synthetic_coord = True`，仅作可视化排布，不冒充真实 GIS 宗地。
4. **中央政府（`GovernmentMesaAgent`，唯一强化学习主体）**：统一管理四个政策区的年度共同增量预算，仅观测滞后一期的区域汇总公共指标，输出四区政策工具与预算限额组合。

### 1.3 Process Overview and Scheduling（年度 7 步因果时序）
每一年度 `AgriSuccessionMesaModel.step()` 严格按以下顺序执行：
1. **期初结转与耕地地力底盘核拨**：结转各主体营运资金、储蓄与在履租约；对原承包户核拨耕地地力保护补贴（启用禁荒条款时，上期完全闲置地块取消当年地力补贴资格）。
2. **政府滞后观察与增量政策公告**：在 `V2.2` 净版（`v2_2_clean`）中，政府读取 $t-1$ 年四区各自 `4` 项滞后公共指标（粮食物理耕种率、耕地闲置率、在租流转率与春耕资金紧缺户比例，含截距共 `17` 维；早期 `v2_25` 另含流转未吸纳率，共 `21` 维），公告当年四区增量工具（`none` / `producer_pre` / `producer_post` / `scale_takeover_pre` / `scale_takeover_post` / `service_trusteeship` / `order_farming`）及单亩上限。
3. **跨年在履租约结算与违约退回**：在履多期合同优先扣付当年租金；营运资金不足以支付在履租金的主体触发违约，地块退回原权利户。
4. **农户自营保留与挂牌转出决策**：600 调查户在同一套 AHM-PMP 净剩余口径下比较全留、全转出与部分转出的预期收益，生成子市场挂牌地块池。
5. **省级子市场序贯增量影子价格竞租**：候选农户与三类规模主体按新增地块前后整户优化净收益差（`RegMAS getShadowPrice` + `AgriPoliS` 报价折减系数 $\beta = 0.68$）报价，支持中点议价与含保留价第二价格两种清算规则；同一权利户挂牌包只计收一次新签合同费（消除记录切碎导致的重复收费）；每成交一笔立即扣减买方营运资金与工日并刷新后续地块估值；流拍地块允许原户在剩余资源可行时有条件回撤复耕。
6. **农忙 PMP 生产规划与紧预算不动点核定**：各主体在最终实际经营面积上求解分段解析 KKT 方程；若区域总申报额超出区域预算上限，通过不动点等比例核减有效费率，确保 `0 <= 实付 <= 承诺 <= 预算预留`。
7. **天气冲击、口粮自留核销与双边复式审计**：实现作物收获，调查户先扣留满足 `foodc` 的实物口粮，余粮按产地价变现进入现金流（缺口按含 `15%` 购销价差的零售价现金外购）；兑现产后核验补贴，更新次年营运资金与企业存续状态，执行 ` _verify_region_conservation()` 守恒断言并写入 `mesa.DataCollector`。

## 2. Design Concepts & Decision Equations（决策方程）

### 2.1 非分离家庭劳动、MP-MAS 口粮价格带与 Howitt 凹二次 PMP
设主体 $i$ 经营物理面积 $A_i$、复种上限 $\kappa_i$、实际播种总亩次 $S \le \kappa_i A_i$、粮食播种占比 $\theta \in [0, 1]$（粮播亩次 $x_g = \theta S$，经作亩次 $x_c = (1-\theta)S$）。其预期经济净剩余为：
$$\Pi_i(\theta, S) = p_{i,g} y_{i,g} x_g + r_c x_c + B^{\text{pre}}_i + B^{\text{post}}_i - C^{\text{mat}}_i(x_g, x_c) - C^{\text{mach,net}}_i(x_g, x_c) - C^{\text{lab}}_i(x_g, x_c) - F_i - \Phi^{\text{PMP}}_i(\theta, S) - \Omega^{\text{food}}_i(x_g)$$
其中：
- **生产托管价格楔子**：$C^{\text{mach,net}}_i = \max(0, c^{\text{mach}}_g - d_{\text{svc}}) x_g + c^{\text{mach}}_c x_c$，只有实际发生农机作业才能享受 $d_{\text{svc}}$ 减免，不可挪付地租；
- **三段劳动成本（de Janvry et al., 1991）**：依次动用农闲保留工日（影子成本 $w_{\text{res}} = 0.12 w_{\text{hire}}$）、非农竞争窗口工日（$w_{\text{comp}} = \min(w_{\text{opp}}, w_{\text{hire}})$）和付费外雇工日（$w_{\text{hire}}$）；
- **Howitt（1995）一阶齐次凹二次成本**：$\Phi^{\text{PMP}}_i(\theta, S) = \frac{1}{2}\gamma S (\theta - \theta^{\text{ref}}_i)^2 + \Delta\pi_0 x_c$，保证基期无政策扭曲时一阶条件精确还原观测份额；
- **口粮购销价差惩罚（MP-MAS）**：当收获粮低于 `foodc` 口粮需求 $Q^{\text{sub}}_i$ 时，$\Omega^{\text{food}}_i = \tau_{\text{mkt}} p_{i,g} \max(0, Q^{\text{sub}}_i - y_{i,g} x_g)$；
- **春耕统一流动性约束**：$C^{\text{mat}}_i + C^{\text{mach,net}}_i + \alpha_{\text{hire}} w_{\text{hire}} L^{\text{hire}}_i - B^{\text{pre}}_i \le W^{\text{open}}_i$。

### 2.2 对称地租价格—面积分解与同地块交集价差
对政策路径 $P$ 与配对基准 $P_0$，当两侧在租面积 $A_P, A_0 > 0$ 时，总租金差 $\Delta R = R_P - R_0$ 精确对称分解为：
$$\Delta R = \underbrace{\frac{A_P + A_0}{2}(r_P - r_0)}_{\Delta R_{\text{price}}\text{（纯单位亩租效应）}} + \underbrace{\frac{r_P + r_0}{2}(A_P - A_0)}_{\Delta R_{\text{area}}\text{（租地面积数量效应）}}$$
并在同一年度两侧共同出租的同一批地块集合 $\mathcal{L}_P \cap \mathcal{L}_0$ 上单列面积加权亩租差 $\Delta r_{\text{common}}$。

## 4. V2.1 设定纠偏记录与反硬编码审计（2026-11-28）

历史标签 `mesa-agri-abm-20261127-v2.1`（提交 `644d957`，结果归档于 `结果_V2_1深化/`，对应旧稿 `论文主稿_V2_1含过度参数假设归档.md`）在独立复核中检出四项违反“零硬编码与内生微观理性”红线的问题，特此如实登记存档，并已从正式 `V2.2` 主模型与正式论文结论中彻底剥离：

1. **工程概念虚假包装**：所谓“农机北斗与合同售粮多源交叉核验（`@xver`）”，在程序内部并未构建真实的空间轨迹或台账匹配流程，实质仅是将预设查处概率标量从 `0.084`（`base_audit_rate=0.28 × local_audit_accuracy=0.30`）切换为 `0.88` 并按灾害年乘以固定系数 `0.55`；以此标注为“北斗多源交叉核验”及“微气象信号干扰提取”缺乏微观程序与数据对应关系。
2. **行号取模虚构合规属性与合成套利者**：在 NFPS 问卷并无合规倾向上测字段的情况下，`V2.1` 曾利用调查户行号取模 `0.50 + 0.45 * ((row.Index * 7) % 11) / 10.0` 为 600 户真实调查农户分配 `compliance_propensity`，并人为设定单产打 `0.82` 折的合成套利主体 `SPEC_*`（与未通过数据核验不得赋予异质性假设相违背）。
3. **非最优化强制减产与阈值硬截断归零**：道德风险损失并非主体权衡“节省农资成本 vs. 期望罚款及减产损失”后的利润最大化选择，而是通过固定公式 `shading_rate = min(0.28, 0.35 * shading_incentive)` 强迫农户在自营收益大幅受损的情况下削减投入并拉低单产；同时在 `exp_clawback_mult >= 0.92 / 0.95` 时通过 `if` 条件直接截断，制造了“漏损归零 (`0.000`)”的机械假象；订单粮零虚报亦系 `if` 条件将 `order_farming` 排除在虚报分支之外所致，而非内生约束结果。
4. **未经微观测算的全区免费单产外部性与手工退坡折线**：`enable_service_capacity_accumulation` 模块假设局部生产托管投入可触发区域成熟度指数并使全区所有农户（含未受补者）免费获得高达 `24%` 农机降费、`14%` 省工与 `3.2%` 单产提升，同时人为写入 `svc_mat > 0.55` 折线退坡因子以诱导 `Gov-RL` 切换动作；这使托管增粮从 `V2.0` 实测农机费口径下的 `+484.93` 吨（约 `51` kg/百元）膨胀至 `+1,450～+1,519` 吨（约 `245` kg/百元），属于未校准的模型放大幅度。

上述 `V2.1` 负结果档案（代码提交 `644d957` 与 `结果_V2_1深化/`）继续留存作方法论教训备查，但**不作为本项目科学结论与政策评价依据**。
