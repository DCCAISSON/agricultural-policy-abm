# CLES收入计算详细说明

## 一、总收入计算公式

根据 `scripts/build_composite_indicators.py` 中的 `compute_income_components` 函数，**家庭总收入**的计算公式为：

```
家庭总收入 = 农业收入 + 非农收入 + 转移性收入 + 财产性收入
```

## 二、各项收入组成部分及对应CLES题项

### 2.1 农业收入（Agricultural Income）

**计算公式**：
```
农业收入 = 种植收入 + 畜牧水产收入
```

#### （1）种植收入（Crop Income）

**计算方式**：
```
种植收入 = 种植收入（毛收入 - 成本）
种植毛收入 = Σ(e105a{i} × e106a{i})  for i in 1-6
种植成本 = Σ(单位成本 × e101a{i})  for i in 1-6
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `e101a1-e101a6` | E1-01 | 种植面积 | 亩 | 6种作物的种植面积 |
| `e105a1-e105a6` | E1-05 | 出售数量 | 斤 | 6种作物的出售数量 |
| `e106a1-e106a6` | E1-06 | 出售单价 | 元/斤 | 6种作物的出售单价 |
| `e108a1-e108a6` | E1-08 | 种子成本 | 元/亩 | 成本组成部分 |
| `e109a1-e109a6` | E1-09 | 化肥成本 | 元/亩 | 成本组成部分 |
| `e110a1-e110a6` | E1-10 | 农药成本 | 元/亩 | 成本组成部分 |
| `e111a1-e111a6` | E1-11 | 机械成本 | 元/亩 | 成本组成部分 |
| `e112a1-e112a6` | E1-12 | 其他成本 | 元/亩 | 成本组成部分 |
| `e114a1-e114a6` | E1-14 | 雇工成本 | 元/亩 | 成本组成部分 |
| `e117a1-e117a6` | E1-17 | 其他成本 | 元/亩 | 成本组成部分 |

**计算逻辑**：
- 毛收入 = 出售数量 × 出售单价（6种作物分别计算后加总）
- 成本 = 各项成本（种子、化肥、农药、机械、雇工等）× 种植面积（6种作物分别计算后加总）
- 种植收入 = max(0, 毛收入 - 成本)  # 确保不为负

#### （2）畜牧水产收入（Livestock Income）

**计算方式**：
```
畜牧水产收入 = Σ(经营毛收入 - 经营成本)  for i in 1-6
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `e205a1-e205a6` | E2-05 | 经营成本 | 元 | 6种畜牧水产品的经营成本 |
| `e206a1-e206a6` | E2-06 | 经营毛收入 | 元 | 6种畜牧水产品的经营毛收入 |

**计算逻辑**：
- 每种畜牧水产品的净收入 = 经营毛收入 - 经营成本
- 畜牧水产收入 = Σ(净收入) for 6种产品，且确保不为负

### 2.2 非农收入（Non-Agricultural Income）

**计算公式**：
```
非农收入 = 工资性收入 + 自营收入
```

#### （1）工资性收入（Wage Income）

**计算方式**：
```
工资性收入 = Σ(a215a{i})  for i in 1-9
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `a215a1` | A2-15 | 非农工资总收入(元)1 | 元 | 家庭成员1的非农工资收入 |
| `a215a2` | A2-15 | 非农工资总收入(元)2 | 元 | 家庭成员2的非农工资收入 |
| ... | ... | ... | ... | ... |
| `a215a9` | A2-15 | 非农工资总收入(元)9 | 元 | 家庭成员9的非农工资收入 |

**说明**：A2-15题项询问"非农工资总收入（元）"，需要加总所有家庭成员（最多9人）的非农工资收入。

#### （2）自营收入（Self-Employment Income）

**计算方式**：
```
自营收入 = max(0, 自营毛收入 - 自营成本)
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `e403` | E4-03 | 若是工商业 2020年经营收入（元） | 元 | 创业经营毛收入 |
| `e404` | E4-04 | 若是工商业 2020年经营成本（元） | 元 | 创业经营成本 |

**计算逻辑**：
- 自营收入 = max(0, e403 - e404)

---

### 2.3 转移性收入（Transfer Income）

**计算公式**：
```
转移性收入 = B2项收入 + B1项中的转移性收入
```

#### （1）B2项收入（政府扶持情况）

**计算方式**：
```
B2项收入 = Σ(b20{i})  for i in 1-10
         + b210a + b210b  # b210有a/b两列
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `b201` | B2-01 | 政府补贴收入 | 元 | 总补贴收入 |
| `b202` | B2-02 | 其中：种植业补贴 | 元 | 种植业补贴 |
| `b203` | B2-03 | 养殖业补贴 | 元 | 养殖业补贴 |
| `b204` | B2-04 | 农机购置补贴 | 元 | 农机补贴 |
| `b205` | B2-05 | 扶贫补贴（仅建档立卡户填写） | 元 | 扶贫补贴 |
| `b206` | B2-06 | 其中：资产收益类项目分红 | 元 | 资产收益分红 |
| `b207` | B2-07 | 贫困慰问金 | 元 | 慰问金 |
| `b208` | B2-08 | 教育补助 | 元 | 教育补助 |
| `b209` | B2-09 | 公益性岗位补助 | 元 | 公益性岗位补助 |
| `b210` | B2-10 | 其他（请注明） | 元 | 其他补贴 |
| `b210a` | B2-10a | 其他补贴（a列） | 元 | b210的a列 |
| `b210b` | B2-10b | 其他补贴（b列） | 元 | b210的b列 |

#### （2）B1项中的转移性收入

**计算方式**：
```
B1转移性收入 = b105 + b107 + b109 + b110
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `b105` | B1-05 | 离退休金、养老金（针对老年群体） | 元 | 养老金收入 |
| `b107` | B1-07 | 家庭非常住人口给家里的汇款（转账） | 元 | 汇款收入 |
| `b109` | B1-09 | 变卖非生产性资产（如房屋、车辆等）所得 | 元 | 资产变卖收入 |
| `b110` | B1-10 | 其他收入 | 元 | 其他收入 |

**说明**：这些收入虽然属于B1项，但被归类为转移性收入。

### 2.4 财产性收入（Property Income）

**计算公式**：
```
财产性收入 = B1项中的财产性收入 + 宅基地流转收入
```

#### （1）B1项中的财产性收入

**计算方式**：
```
B1财产性收入 = b101 + b102 + b103 + b104
```

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `b101` | B1-01 | 非农资产租赁收入（房屋、厂房、机械等） | 元 | 资产租赁收入 |
| `b102` | B1-02 | 利息、股息、红利收入 | 元 | 金融资产收入 |
| `b103` | B1-03 | 其中：集体经济分红 | 元 | 集体经济分红 |
| `b104` | B1-04 | 征地补偿款 | 元 | 征地补偿 |

#### （2）宅基地流转收入

**对应CLES题项**：

| 变量名 | CLES题项 | 中文释义 | 单位 | 说明 |
|--------|---------|---------|------|------|
| `c309` | C3-09 | 宅基地流转收入 | 元 | 宅基地相关收入 |

## 三、完整收入计算流程

### 3.1 代码实现位置

**文件**：`scripts/build_composite_indicators.py`

**函数**：`compute_income_components(df)`

### 3.2 计算步骤

```python
# 步骤1：计算农业收入
# 1.1 种植收入
crop_revenue = Σ(e105a{i} × e106a{i})  # 6种作物
crop_cost = Σ(各项成本 × e101a{i})     # 6种作物
crop_income = max(0, crop_revenue - crop_cost)

# 1.2 畜牧水产收入
livestock_income = Σ(max(0, e206a{i} - e205a{i}))  # 6种产品

# 1.3 农业收入
agricultural_income = crop_income + livestock_income

# 步骤2：计算非农收入
# 2.1 工资性收入
wage_income = Σ(a215a{i})  # 9个家庭成员

# 2.2 自营收入
self_emp_income = max(0, e403 - e404)

# 2.3 非农收入
non_ag_income = wage_income + self_emp_income

# 步骤3：计算转移性收入
# 3.1 B2项收入
b2_income = Σ(b20{i}) + b210a + b210b  # 10项补贴

# 3.2 B1项中的转移性收入
b1_transfer = b105 + b107 + b109 + b110

# 3.3 转移性收入
transfer_income = b2_income + b1_transfer

# 步骤4：计算财产性收入
# 4.1 B1项中的财产性收入
b1_property = b101 + b102 + b103 + b104

# 4.2 宅基地流转收入
property_income = b1_property + c309

# 步骤5：计算总收入
total_income = agricultural_income + non_ag_income + transfer_income + property_income
```

## 五、注意事项

### 5.1 数据缺失处理

- 所有缺失值使用 `fillna(0)` 填充为0
- 使用 `_clean_income_series()` 函数处理异常值

### 5.2 收入不为负

- 所有收入计算都使用 `.clip(lower=0.0)` 确保不为负
- 种植收入 = max(0, 毛收入 - 成本)
- 畜牧收入 = max(0, 毛收入 - 成本)
- 自营收入 = max(0, 毛收入 - 成本)

### 5.3 极端值处理

- 对总收入进行温和的Winsorize处理（99.5%分位数上限）
- 避免极端值影响分位数计算

### 5.4 单位转换

- CLES原始数据单位：**元**
- 模型中使用单位：**万元**（在初始化时转换）

## 六、与模型中的收入计算对应关系

### 6.1 模型中的收入变量

在 `FarmerAgent` 中，收入被分解为：

| 模型变量 | CLES对应 | 说明 |
|---------|---------|------|
| `agricultural_income` | 农业收入（种植+畜牧） | 对应CLES的农业收入 |
| `off_farm_income` | 工资性收入 | 对应CLES的a215a系列 |
| `land_rental_income` | 资产租赁收入 | 对应CLES的b101（部分） |
| `subsidy_income` | 政府补贴 | 对应CLES的b201-b210系列 |

### 6.2 差异说明

**模型中的收入计算**：
- 基于仿真过程中的决策和交易计算
- 不是直接从CLES数据读取
- CLES数据主要用于初始化参数和校准

**CLES数据的作用**：
- 用于初始化农户的初始收入水平
- 用于校准模型参数
- 用于验证模型输出
