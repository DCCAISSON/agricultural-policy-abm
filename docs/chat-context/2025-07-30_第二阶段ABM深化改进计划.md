# 第二阶段：ABM深化改进计划

**启动时间**: 2025-07-30  
**预期完成**: 2025-09-30 (2个月)  
**核心目标**: 从"经济学理论驱动"转向"充分利用ABM方法论优势"

## 🎯 核心改进方向

基于ABM研究前沿和方法论优势，第二阶段聚焦四个关键维度的深化：

### 1. 社会学习机制 (Social Learning) - 【最高优先级】
**理论依据**: 从完全理性到有限理性，引入主体间互动与信息扩散

#### 🔬 **当前问题分析**
- **过度理性假设**: 农户能够精确计算复杂效用函数，获得完美信息
- **孤立决策**: 每个主体独立计算，忽略了邻居影响和社会网络
- **缺乏涌现**: 无法捕捉"羊群效应"、技术扩散等社会现象

#### ✅ **具体实施方案**
1. **邻居观察机制**: 农户在作物选择前观察社会网络中邻居的历史收益
2. **启发式决策规则**: 
   - 如果邻居种植经济作物平均收益 > 自己上年收益的1.2倍 → 倾向选择经济作物
   - 引入"从众概率"：P(选择X作物) = 0.6×前景理论效用 + 0.4×邻居影响
3. **信息扩散机制**: 成功案例在社会网络中传播，影响决策

### 2. 动态风险偏好学习 - 【第二优先级】
**理论依据**: 财富效应与经验学习，风险偏好内生化

#### 🔬 **当前问题分析**
- **静态风险偏好**: `risk_aversion`固定不变，忽略了财富效应
- **缺乏学习**: 主体不从成功/失败中调整行为模式
- **路径依赖缺失**: 无法探索早期成功对长期策略的锁定效应

#### ✅ **具体实施方案**
1. **财富效应函数**: 
   ```python
   new_risk_aversion = base_risk_aversion * wealth_adjustment_factor
   wealth_factor = min(2.0, max(0.5, initial_capital / current_capital))
   ```
2. **经验学习**: 连续成功降低风险偏好，连续失败提高风险偏好
3. **参考点适应**: 成功经历提升参考点，强化冒险倾向

### 3. 去中心化空间搜索 - 【第三优先级】
**理论依据**: 空间化本地搜索，社会网络嵌入的市场机制

#### 🔬 **当前问题分析**
- **中央撮合**: "上帝之手"匹配，偏离ABM去中心化精神
- **忽略空间**: 土地整合无空间特征，缺乏成片集中
- **网络缺失**: 忽略熟人关系在土地流转中的重要作用

#### ✅ **具体实施方案**
1. **空间搜索半径**: 主体在地理邻域内搜索土地
2. **社会网络优先**: 优先向社会关系好的邻居询价
3. **成片整合倾向**: 企业优先租用邻近已有土地的地块

### 4. 环境异质性与空间互动 - 【基础设施改进】
**理论依据**: 主体-环境互动，空间嵌入的决策过程

#### 🔬 **当前问题分析**
- **同质化土地**: 所有地块相同，脱离农业生产的自然基础
- **抽象空间**: 缺乏地理特征和空间约束
- **环境反馈缺失**: 土地质量不影响作物选择和租金

#### ✅ **具体实施方案**
1. **土地质量分层**: 每个地块具有quality属性(0-1)
2. **质量-产量函数**: 产量 = base_yield × land_quality × farming_ability
3. **差异化租金**: 高质量土地引发更激烈竞争

## 🎯 预期效果

### 理论贡献
- **方法论创新**: 首个结合前景理论与社会学习的农业政策ABM
- **涌现现象**: 捕捉羊群效应、空间集聚、路径依赖等复杂现象
- **政策洞察**: 揭示政策如何通过社会网络放大或抑制影响

### 学术价值
- **顶级期刊**: 符合AJAE、JEEM等顶级期刊的方法论要求
- **国际影响**: 为全球农业政策ABM研究提供新范式
- **实践指导**: 为政策制定提供更贴近现实的仿真工具

### 模型优势
- **真实性**: 决策过程更符合农户实际行为
- **丰富性**: 能够探索更多样的政策情景
- **预测性**: 提高政策效果预测的准确性

### 向后兼容性
- 保留原有的完全理性决策作为可选模式
- 通过配置参数控制社会学习权重
- 渐进式改进，确保模型稳定性

### 性能优化
- 高效的空间搜索算法
- 智能的社会网络更新机制
- 可配置的复杂度等级

### 验证框架
- 对比分析：完全理性 vs 社会学习
- 空间分析：土地集中的空间模式
- 行为分析：风险偏好的演化轨迹
