## 权威文献检索与理论基础

### 1. 前景理论 (Kahneman & Tversky, 1979)
**应用领域**：农户在不确定性下的土地利用与生产决策
**核心参数**：
- 损失规避系数：λ = 1.8-2.2（基于实验数据）
- 风险态度参数：α = 0.75-0.85（基于农户调查）
- 概率加权参数：γ = 0.65-0.75（行为经济学实验）

**实现方式**：
```python
# 价值函数
v(x) = x^α (x ≥ 0)
v(x) = -λ(-x)^α (x < 0)

# 概率加权函数
w(p) = p^γ / [p^γ + (1-p)^γ]^(1/γ)
```

### 2. 企业异质性理论 (Melitz, 2003)
**应用领域**：农业企业利润最大化决策
**核心机制**：
- 生产效率差异：企业比农户高15-20%
- 规模经济效应：Efficiency = 1.15 × BaseEfficiency
- 投资决策：基于投资回报率阈值（10%）
- 空间扩张策略：优先邻近地块

**实现方式**：
```python
# 投资分配函数
I_total = I_tech + I_expansion
I_tech = β_tech × π
I_expansion = β_expansion × π

# 技术升级函数
T_new = T_old + I_tech / K_tech
```

### 3. 空间经济学理论 (Fujita et al., 1999)
**应用领域**：空间价格梯度、运输成本、邻域效应
**核心机制**：
- 空间价格梯度：P(x,y) = P_market - α × d(x,y)
- 运输成本：TransportCost = distance × costRate × area
- 邻域效应：技术扩散、信息传播
- 空间聚集：企业扩张的空间策略

### 4. 技术扩散理论 (Rogers, 2003)
**应用领域**：农业技术从企业向农户扩散
**核心机制**：
- 扩散概率：基于空间距离和邻域关系
- 技术采用：农户模仿企业技术
- 扩散率：0.05-0.12（基于农业技术推广数据）
