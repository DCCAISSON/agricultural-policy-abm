# 收入计算与单位转换说明

## 一、总收入计算方式

### 1.1 总收入的计算公式

**总收入 = 农业经营收入 + 工资性收入 + 财产性收入 + 转移性收入**

### 1.2 各项收入的来源变量

| 收入类型 | 变量名 | 中文释义 | 数据来源 |
|---------|--------|---------|---------|
| **农业经营收入** | `e206a1` | 2020年经营毛收入（元） | E2-05 经营毛收入 |
| **工资性收入** | `a215a1` ~ `a215a9` | 非农工资总收入(元)1-9 | A2-15 非农工资总收入（元） |
| **财产性收入** | `b101` | 非农资产租赁收入（元） | B1-01 非农资产租赁收入 |
| | `b102` | 利息、股息、红利收入（元） | B1-02 利息、股息、红利收入 |
| **转移性收入** | `b201` | 政府补贴收入（元） | B2-01 政府补贴收入 |

### 1.3 计算逻辑

1. **农业经营收入**：直接使用 `e206a1`（2020年经营毛收入）
2. **工资性收入**：加总所有家庭成员的工资性收入（`a215a1` + `a215a2` + ... + `a215a9`）
3. **财产性收入**：加总 `b101`（资产租赁收入）和 `b102`（利息股息红利收入）
4. **转移性收入**：直接使用 `b201`（政府补贴收入）
