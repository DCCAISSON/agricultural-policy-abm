# 模型运行与可视化指南

## 一、如何运行模型

### 1.1 单次仿真运行

**基本命令**：
```bash
python runner.py --mode single
```

**完整参数示例**：
```bash
python runner.py --mode single --config config/master_config.yaml --steps 50 --seed 42 --output-base results
```

**参数说明**：
- `--mode single`: 运行单次仿真
- `--config`: 配置文件路径（默认：`config/master_config.yaml`）
- `--steps`: 仿真步数（覆盖配置文件中的设置）
- `--seed`: 随机种子（覆盖配置文件中的设置）
- `--output-base`: 结果输出根目录（默认：`results`）

### 1.2 运行后自动生成可视化

运行完成后，结果会保存在 `results/single_runs/YYYY-MM-DD_HH-MM/` 目录下，包含：

1. **数据文件**：
   - `model_data.csv`: 模型层面的时间序列数据
   - `agent_data.csv`: 智能体层面的数据

2. **可视化图表**（在 `figures/` 目录）：
   - 生计类型演化图
   - 收入分布图
   - 土地流转图
   - 其他关键指标图

3. **综合可视化**（在 `comprehensive_visualization/` 目录）：
   - 作物类型农户生计类型演化图
   - 企业类型演化图
   - 收入不平等趋势图

### 1.3 生成综合可视化

运行完模型后，可以单独运行综合可视化分析：

```bash
python analysis/comprehensive_indicators_visualization.py
```

这会自动找到最新的仿真结果目录，并生成所有综合可视化图表。

### 1.4 Mesa浏览器可视化

## 二、收入计算说明

### 2.1 收入计算逻辑（已修正）

**总收入（gross_income / total_income）**：
```python
gross_income = agricultural_income + land_rental_income + subsidy_income + off_farm_income
total_income = gross_income  # 向后兼容
```

**总支出（total_expense）**：
```python
total_expense = production_cost + land_rental_expense
```

**净利润（net_income）**：
```python
net_income = gross_income - total_expense
```

**可支配收入（disposable_income）**：
```python
disposable_income = net_income * (1 - savings_rate)  # 储蓄率默认20%
```

### 2.2 数据收集

现在数据收集器中同时收集：
- `Gross_Income`: 总收入（未减去支出）
- `Total_Income`: 总收入（向后兼容，等同于Gross_Income）
- `Net_Income`: 净利润（总收入 - 总支出）
- `Disposable_Income`: 可支配收入（用于消费）

**建议**：在分析时使用 `Net_Income`（净利润）作为主要收入指标，因为它更准确地反映了农户的实际经济状况。

## 三、效用福利计算（已实现）

### 3.1 理论框架

根据理论框架，农户的效用函数包括：

1. **食品消费效用**：
   - 基本需求食物（essential food）
   - 高端食物（luxury food）
   - 效用函数：`U_food = (C_essential^alpha) * (C_luxury^(1-alpha))`
   - 其中 alpha = 0.7（基本需求食物权重）

2. **闲暇效用**：
   - 闲暇时间带来的效用
   - 效用函数：`U_leisure = gamma * log(1 + L_leisure)`
   - 其中 gamma = 100（闲暇效用系数）

3. **总效用**：
   ```
   U_total = U_food + U_leisure
   ```

4. **福利指数**：
   ```
   Welfare_Index = U_total / max_utility  # 归一化到0-1
   ```

### 3.2 实现细节

**消费决策**：
- 在可支配收入约束下分配消费预算
- 基本需求食物：至少满足最低需求（1000元），剩余按偏好分配
- 高端食物偏好系数：基于生计策略、年龄和城市经历计算
  - Non_Farmer: 0.8（更多城市经历）
  - Pluriactive: 0.5
  - Pure_Farmer: 0.2

**闲暇时间计算**：
- 闲暇时间 = 总时间（365天）- 农业劳动 - 非农劳动

### 3.3 数据收集

现在数据收集器中收集以下效用指标：

**模型层面**：
- `Average_Utility`: 平均总效用
- `Average_Welfare_Index`: 平均福利指数
- `Average_Food_Utility`: 平均食品消费效用
- `Average_Leisure_Utility`: 平均闲暇效用

**智能体层面**：
- `Total_Utility`: 总效用
- `Food_Utility`: 食品消费效用
- `Leisure_Utility`: 闲暇效用
- `Welfare_Index`: 福利指数
- `Consumption_Essential`: 基本需求食物消费量
- `Consumption_Luxury`: 高端食物消费量
- `Leisure_Time`: 闲暇时间（天）

## 五、效用可视化示例

### 5.1 使用Python分析效用数据

运行模型后，可以使用以下代码分析效用变化：

```python
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# 加载数据
agent_data = pd.read_csv('results/single_runs/YYYY-MM-DD_HH-MM/agent_data.csv')

# 按时间步分析平均效用
utility_trends = agent_data.groupby('Step').agg({
    'Total_Utility': 'mean',
    'Food_Utility': 'mean',
    'Leisure_Utility': 'mean',
    'Welfare_Index': 'mean',
    'Net_Income': 'mean'
}).reset_index()

# 绘制效用演化图
fig, axes = plt.subplots(2, 2, figsize=(15, 10))
axes[0, 0].plot(utility_trends['Step'], utility_trends['Total_Utility'], label='总效用')
axes[0, 0].set_title('平均总效用演化')
axes[0, 0].set_xlabel('时间步')
axes[0, 0].set_ylabel('效用')
axes[0, 0].legend()
axes[0, 0].grid(True)

axes[0, 1].plot(utility_trends['Step'], utility_trends['Food_Utility'], label='食品效用')
axes[0, 1].plot(utility_trends['Step'], utility_trends['Leisure_Utility'], label='闲暇效用')
axes[0, 1].set_title('食品与闲暇效用演化')
axes[0, 1].set_xlabel('时间步')
axes[0, 1].set_ylabel('效用')
axes[0, 1].legend()
axes[0, 1].grid(True)

axes[1, 0].plot(utility_trends['Step'], utility_trends['Welfare_Index'], label='福利指数')
axes[1, 0].set_title('平均福利指数演化')
axes[1, 0].set_xlabel('时间步')
axes[1, 0].set_ylabel('福利指数')
axes[1, 0].legend()
axes[1, 0].grid(True)

axes[1, 1].scatter(utility_trends['Net_Income'], utility_trends['Total_Utility'], alpha=0.5)
axes[1, 1].set_title('净利润与总效用关系')
axes[1, 1].set_xlabel('净利润')
axes[1, 1].set_ylabel('总效用')
axes[1, 1].grid(True)

plt.tight_layout()
plt.savefig('utility_analysis.png', dpi=300)
plt.show()
```

### 5.2 按生计类型分析效用

```python
# 按生计类型分析效用差异
utility_by_strategy = agent_data.groupby(['Step', 'Livelihood_Strategy']).agg({

# 绘制不同生计类型的效用对比

plt.ylabel('总效用')
plt.legend()

```
